## ビザについて

| 在留資格                 | 説明 |
| :----------------------- | ---- |
| 技術・人文知識・国際業務 | 最も一般的な就労ビザ。日本の企業と雇用契約を結び、エンジニア・デザイナー・翻訳・営業など、専門的な知識や技術を要する業務に従事する外国人に付与される。大卒以上（または同等の実務経験）が要件。在留期間は1年・3年・5年。 |
| 経営・管理               | 日本での事業の経営・管理を行う者に付与されるビザ。2025年10月16日以降、原則として資本金等3,000万円以上・対象となる常勤職員1人以上などが要件（既存在留者には経過措置あり）。事業計画書の提出が必須で、入国管理局による審査が厳しい。在留期間は1年・3年・5年。 |
| 家族滞在                 | 在留資格を持つ外国人の扶養配偶者・子に付与されるビザ。対象は「技術・人文知識・国際業務」「経営・管理」「留学」などの在留資格を持つ者の扶養家族。原則として就労不可（資格外活動許可で週28時間まで可能）。 |
| 技能実習                 | 発展途上国等の外国人を一定期間（最長5年）日本で受け入れ、技術・技能・知識を移転し、各国の経済発展を担う人材を育成する制度。1号（最長1年）・2号（最長2年）・3号（最長2年）に分かれる。企業単独型と団体監理型があり、認定された技能実習計画に基づく。 |
| 特定技能                 | 人手不足が深刻な分野（介護・建設・農業・飲食などの指定分野）で、即戦力となる外国人材を受け入れる制度。特定技能1号（在留期間通算5年まで・家族同伴不可）と2号（更新可能・家族同伴可）がある。日本語と技能試験の合格が要件。 |
| 特定活動                 | 上記の在留資格に該当しない特別な活動を行う者に付与される。ワーキングホリデー、外交官の家族、特定のインターンシップ、高度外国人材の配偶者など幅広い。活動内容ごとに個別に要件が定められている。 |
| 高度専門職               | 高度な学術研究・技術を持つ外国人を優遇するポイント制ビザ。学歴・職歴・年収などでポイントを加算し、70点以上で認定。1号の在留期間は5年、2号は無期限。永住許可は別申請で、高度人材の条件を満たせば必要な在留歴が1年又は3年に短縮される。配偶者の就労制限が緩和される。 |
| 企業内転勤               | 海外の支店・関連会社から日本の支店・子会社へ転勤してくる者に付与される。転勤元で1年以上継続して勤務していることが要件。「技術・人文知識・国際業務」と同じ業務内容に従事可能。在留期間は1年・3年・5年。 |
| 文化活動                 | 日本固有の文化・芸術（日本舞踊・華道・茶道・陶芸など）を習得・研究する活動に従事する者に付与。収入を伴う事業は原則不可。在留期間は3年・1年・6ヶ月・3ヶ月。教授や指導者からの推薦状が必要な場合がある。 |
| 留学                     | 日本の大学・短大・専門学校・日本語学校等で教育を受ける者に付与される。別途、資格外活動許可を受ければ原則週28時間以内のアルバイトが可能。在学中の更新や卒業後の就労資格への変更には、それぞれの要件を満たす必要がある。 |
| 短期滞在                 | 観光・親族訪問・ビジネス視察・会議参加など、短期間の活動に付与される。最長90日間。査証免除協定のある国・地域の国籍者はビザ不要。就労活動（報酬を得る業務）は不可。 |
| 日本人の配偶者等         | 日本人と結婚した外国人に付与されるビザ。在留期間は5年・3年・1年・6ヶ月で更新が必要。在留資格上の就労制限なし。離婚・死別時は届出や在留資格の見直しが必要。日本人の実子・特別養子も対象となる。永住権申請の要件も緩和される。 |
| 永住者の配偶者等         | 永住者・特別永住者の配偶者、又はその子として日本で出生し引き続き在留する者が対象。在留資格上の就労制限なし。在留期間は5年・3年・1年・6ヶ月。日本人の配偶者と同等の扱いを受けるが、永住権申請には別途要件を満たす必要がある。 |
| 定住者                   | 日系3世や中国残留邦人等、告示又は個別審査の対象となる特別な事情により日本に定住する者に付与される。就労制限なし。在留期間は1年・3年・5年。法務大臣が個別に指定する。 |
| 永住者                   | 在留資格の中で最も自由度が高い。就労制限なし、在留期間の制限なし。原則として10年以上の継続在留が必要（高度専門職は1〜3年）。配偶者や永住者による扶養は必須ではない。素行善良・生計資産要件あり。出国時は再入国許可又はみなし再入国許可の手続に注意する。 |

## 各类签证的申请要求

> 核对日期：2026-11-03。以下按上表顺序，用中文说明主要条件和常见材料，保留日文正式名称。
>
> 严格来说，“签证（査証）”用于申请入境，“在留资格”决定入境后的活动与停留。首次申请、在日本变更资格、续签，以及公司或学校类别不同，材料清单会有差异；以下不是所有情形的完整清单。

### 通用准备

- **身份材料**：对应申请表、规定照片及护照；在日本申请变更或续签时通常还需在留卡。
- **申请理由**：工作合同、录取证明、亲属关系或活动计划等，须与实际活动一致。
- **境外首次申请中长期居留**：通常先由日本接收方或符合条件的代理人申请在留资格认定证明书（COE），再向管辖使领馆申请签证；COE不等于签证，也不保证入境。短期滞在一般不走COE程序。
- **外文文件**：按要求附日文译文；原件、复印件及文件有效期限，以具体清单为准。

来源：[外务省：COE与长期签证说明](https://www.mofa.go.jp/mofaj/toko/visa/chouki/visa5.html)、[入管：在留手续问答](https://www.moj.go.jp/isa/immigration/faq/kanri_qa.html)。

### 1. 技術・人文知識・国際業務（技术・人文知识・国际业务）

**主要要求**：

- 与日本公私机构有持续性合同，实际从事专业技术、人文知识或国际业务，不能只是流水线、体力劳动或简单服务工作。
- **技术、人文知识类**：通常须有相关大学学历或同等以上教育，或符合规定的日本专门学校学历；也可通过原则上10年以上相关实务经验满足要求，相关专业学习期间可计入。指定信息处理考试、资格等另有例外。
- **国际业务类**：原则上须有3年以上相关实务经验；大学毕业者从事翻译、口译或语言教学时，可适用经验年限例外。
- 报酬不低于从事同类工作的日本人，雇主有真实业务及持续支付报酬的能力。
- 主要依靠语言能力从事翻译、口译等对人业务时，须符合所用语言CEFR B2相当能力要求；并非所有工程师岗位统一要求N2。2026-04-15起，类别3、4机构的相关申请有追加材料要求。

**常见材料**：合同或劳动条件通知书、岗位说明、学历及成绩资料、经历证明、公司登记和经营财务资料，适用时另交语言能力及追加确认材料。

来源：[入管：技人国申请说明](https://www.moj.go.jp/isa/applications/status/gijinkoku)、[学历与经验标准](https://www.moj.go.jp/isa/content/001413895.pdf)、[语言类对人业务要求](https://www.moj.go.jp/isa/content/001460430.pdf)。

### 2. 経営・管理（经营・管理）

**主要要求（2025-10-16起的新标准）**：

- 在日本有实际经营使用的事业所，并实质参与经营或管理，不能只注册空壳公司。
- 事业投入的资本金等达到**3,000万日元以上**，法人和个人经营的计算方式不同；新申请不能继续按旧的500万日元标准规划。
- 雇用至少1名符合规定的常勤职员；人数要求的计数对象限日本人、特别永住者、永住者及定住者等身份类在留资格持有人，普通工作签证员工不能替代这一门槛。
- 申请人本人或符合规定的常勤职员须有B2相当日语能力，例如JLPT N2以上等。语言能力职员与上一项人数要求的认定范围并不完全相同。
- 申请人有经营管理或经营业务领域相关的硕士相当以上学位，或3年以上经营管理实务经验。
- 事业计划具体、合理、可实现，并经规定的经营专业人士，如中小企业诊断士、公认会计士或税理士确认。
- 取得行业必要许可，并遵守税务、劳动、社会保险等规定；从事管理业务还须满足相应报酬条件。

**常见材料**：公司登记、资金投入及来源证明、事业所租约与照片、事业计划及专业人士确认、雇员资料、学历或经历、语言证明及行业许可、财务税务资料。

**旧持有人续签**：存在过渡安排，须结合经营情况及满足新标准的可能性等审查，不能直接照搬新申请结论。

来源：[入管：新标准及过渡安排问答](https://www.moj.go.jp/isa/applications/resources/10_00237.html)、[新标准概要](https://www.moj.go.jp/isa/content/001448584.pdf)。

### 3. 家族滞在（家属居留）

**主要要求**：

- 是持规定在留资格者所扶养的合法配偶或子女，实际接受扶养；父母、兄弟姐妹不属于这一类别。
- 扶养人的资格允许携带家属，例如技人国、经营管理、企业内转勤、特定技能2号及符合规定的留学等；技能实习、特定技能1号等不能据此申请普通家族滞在。
- 扶养人有承担家庭生活费的收入、存款或奖学金等，按家庭人数、住房及实际开销判断，没有适用于所有家庭的统一存款金额。

**常见材料**：结婚或出生证明、扶养人的护照及在留卡资料、在职、课税与纳税证明；无工作收入者提交存款或奖学金等证明。

**工作限制**：本资格不允许工作；另获资格外活动许可后，通常可在所有兼职合计每周28小时以内工作，禁止风俗营业相关活动。

来源：[入管：家族滞在材料清单](https://www.moj.go.jp/isa/content/001367761.pdf)、[家属范围问答](https://www.moj.go.jp/isa/immigration/faq/kanri_qa.html)。

### 4. 技能実習（技能实习）

**主要要求**：

- 原则上年满18岁，以学习技能为目的，并计划回国后从事能运用所学技能的工作。
- 接收单位符合规定，实习计划经外国人技能实习机构认定；分企业单独型和团体监理型，并非全部通过监理团体。
- 满足职种、阶段对应的经历及技能要求；转入2号、3号须满足相应技能评价及计划认定条件。
- 劳动合同和报酬符合规定；不得收取保证金或约定违法违约金。
- 日语要求随职种不同，例如介护职种1号原则上要求N4相当、2号原则上要求N3相当，不能当作所有职种的统一门槛。

**常见材料**：认定实习计划、劳动条件、派遣及接收资料、经历和健康资料、各阶段技能或语言证明。

**制度转换**：育成就劳自**2027-04-01**施行，技能实习按过渡规定逐步转换；新申请须核对计划认定申请时间及实习开始时间。

来源：[厚劳省：技能实习生要求](https://www.mhlw.go.jp/content/12000000/001692285.pdf)、[入管：育成就劳及过渡安排](https://www.moj.go.jp/isa/applications/faq/ikusei_qa_00002.html)。

### 5. 特定技能（特定技能）

**主要要求**：

- 原则上年满18岁，健康状况符合要求，与合规接收机构签订特定技能雇用合同，报酬不低于同类日本员工。
- **1号**：原则上通过对应领域技能考试和日语考试。多数领域以JFT-Basic或JLPT N4以上等规定标准证明日语；介护、运输等有追加或较高要求，须按具体业务区分核对。
- 良好完成技能实习2号者，依对应关系可获技能和日语考试豁免；仅有日语豁免不代表技能考试也自动豁免。
- 接收方满足法定条件；1号须有合规支援计划，可委托注册支援机构实施。
- **2号**：满足对应领域的熟练技能考试、实务或管理经验等要求；不是工作满5年就自动升级，适用领域也与1号不同。

**常见材料**：考试或实习修了证明、合同和劳动条件、健康检查、接收机构资料；1号另有支援计划等。

**期限及家属**：1号原则上累计最多5年，原则上不能携带家属；2号可续签且无累计年限上限，符合条件的配偶、子女可申请家族滞在。

来源：[外务省：接收条件](https://www.mofa.go.jp/mofaj/ca/fna/ssw/jp/introduction/index.html)、[入管：特定技能问答](https://www.moj.go.jp/isa/policies/ssw/faq)、[官方考试信息](https://www.ssw.go.jp/about/sswv/exam/)。

### 6. 特定活動（特定活动）

**主要要求**：

- 符合某个明确的告示类别，或获得法务大臣个别指定；不存在适用于所有特定活动的统一学历、收入或日语门槛。
- 工作假期、毕业后继续求职、指定实习、高度人才家属等，各自有不同的国籍、年龄、学历、资金、接收方及期限要求。
- 先确认具体类别，再证明满足该类别条件。例如工作假期有国籍或地区限制，不能认为所有护照持有人均能申请。
- 能否工作以及工作范围，以在留卡及“指定书”的具体许可为准。

**常见材料**：对应活动说明、接收或推荐文件、学历或亲属关系、资金及保险证明等，按具体类别清单准备。

来源：[入管：特定活动说明](https://www.moj.go.jp/isa/content/001389019.pdf)、[官方劳动部门：指定书与工作范围](https://jsite.mhlw.go.jp/osaka-roudoukyoku/content/contents/001833420.pdf)。

### 7. 高度専門職（高度专门职）

**主要要求**：

- 活动属于高度学术研究、高度专业技术或高度经营管理，并满足相应活动本身的条件；达到积分不能替代工作或经营条件。
- 通常按学历、经历、预计年收入、年龄、研究成果、日语等累计**70分以上**，各项加分须有证明。
- 高度专业技术和高度经营管理领域另有最低年收入**300万日元**要求，不能只看积分。
- **1号**在留期间为5年；**2号**通常须以高度专业职1号等规定资格活动3年以上，并满足积分、品行及国益等条件，在留期间无期限。

**常见材料**：积分计算表及各项证明、学历学位、经历、年收入或合同、研究成果或语言证书、所属机构资料。

**永住通道**：符合持续积分及居留等条件时，70分路线可将必要在留年限缩短至3年、80分路线缩短至1年；仍须另行申请并满足其他永住条件。

来源：[入管：高度专门职](https://www.moj.go.jp/isa/applications/status/designatedactivities02_00004)、[官方积分表](https://www.moj.go.jp/isa/content/001451964.pdf)、[高度人才问答](https://www.moj.go.jp/isa/applications/resources/newimmiact_3_qa.html)。

### 8. 企業内転勤（企业内部调动）

**主要要求**：

- 从海外事业所调往同一企业或符合规定关联关系的日本事业所，明确调动期限。
- 调动前原则上在海外事业所连续1年以上从事符合技人国范围的专业业务，不能仅以无关岗位任职经历满足条件。
- 日本岗位也属于技人国范围，报酬不低于同类日本员工。
- 不直接套用技人国的大学学历门槛，但必须符合上述任职及实际工作要求。

**常见材料**：调动命令、过去1年的岗位及薪酬证明、两地公司的关联和登记资料、事业所及财务资料；2026-04-01起的材料清单已有调整。

来源：[入管：企业内转勤](https://www.moj.go.jp/isa/applications/status/intracompanytransfee.html)、[调动经历及合同问答](https://www.moj.go.jp/isa/immigration/faq/kanri_qa.html)。

### 9. 文化活動（文化活动）

**主要要求**：

- 从事无报酬的学术或艺术活动，或专门研究日本特有文化、技艺，或在专家指导下学习。
- 说明具体活动、期间及接收机构或指导者，不能仅用普通旅游或兴趣体验替代专门计划。
- 按活动类型证明相关经历或成果；跟随专家学习时提供指导者专业情况。
- 有覆盖生活及学习费用的存款、奖学金或经费承担者支持。

**常见材料**：活动计划、接收或指导证明、指导者履历、作品或研究成果、经费保障资料。

**工作限制**：主要活动不应获取收入；另做有报酬活动须确认资格外活动许可，不能直接套用留学生打工规则。

来源：[入管：文化活动资料](https://www.moj.go.jp/isa/applications/status/culturalactivities01.html)、[外务省：文化活动](https://www.mofa.go.jp/mofaj/toko/visa/chouki/visa5.html)。

### 10. 留学（留学）

**主要要求**：

- 被符合接收条件的日本学校录取，实际目的为接受教育，满足课程的学历和授课语言要求；并非全部学校统一要求N2。
- 本人或经费承担者能支付学费和生活费，以存款、收入、奖学金等证明，不应把预期兼职收入作为全部保障。
- 日语教育机构的A1相当能力证明已有调整：适用2026年新规者须以考试证明或面试确认等规定方式核实，不能仅凭150小时学习证明替代；部分对象有例外。
- 续签须保持实际就学，提供在学、出勤、成绩及经费资料，不是未毕业就自动续签。

**常见材料**：入学许可、学历及成绩、语言资料、经费支付书、存款及收入证明、经费承担者关系证明，具体由学校协助准备。

**工作及毕业后**：另获资格外活动许可后，平时所有兼职合计原则上每周28小时以内，学校规定长假按每天8小时以内等规定办理；禁止风俗营业相关工作。毕业后工作须另获与岗位相符的资格。

来源：[日本学生支援机构：入境与资金证明](https://www.studyinjapan.go.jp/ja/planning/immigration-procedures/)、[入管：留学](https://www.moj.go.jp/isa/applications/status/student.html)、[日语教育机构新规则](https://www.moj.go.jp/isa/10_00258)。

### 11. 短期滞在（短期停留）

**主要要求**：

- 为旅游、探亲访友、会议、商谈等短期目的，行程合理，并有返程或后续离境安排。
- 本人或经费承担者能够支付旅行及停留费用。
- 是否免签取决于护照国籍、居住地等条件；中国大陆普通护照通常须办签证，不能套用其他国籍的免签规则。
- 旅游、探亲、商务材料不同；中国境内旅游申请按所在领区及指定旅行社等渠道的现行要求办理。

**常见材料**：护照、申请表、照片、行程、身份及经济能力资料；探亲或商务视情况补充邀请理由、亲属关系、身元保证及邀请方资料。

**工作限制**：不得从事有报酬工作或经营有收入的事业。签证有效期、可入境次数与每次获准停留天数是不同概念。

来源：[外务省：中国游客签证](https://www.mofa.go.jp/mofaj/toko/visa/topics/china.html)、[中国申请人短期签证材料](https://www.mofa.go.jp/mofaj/files/100584186.pdf)。

### 12. 日本人の配偶者等（日本人的配偶者等）

**主要要求**：

- 配偶者路线须与日本人有有效法律婚姻及真实持续的夫妻生活，不是登记结婚就必然获批。
- 说明婚姻经过、共同生活安排和经济来源，证明家庭可承担在日生活费用。
- 此资格也包括日本人的特别养子、作为日本人子女出生者，后两类按亲子或收养关系申请。

**常见材料（配偶者）**：日本人户籍誊本、外国结婚证明、问答书、合照及交流记录、住民票、收入纳税或存款资料、身元保证书。

**工作与身份变化**：在留资格本身没有工作种类限制，仍须遵守行业法律。离婚、丧偶须按规定申报，后续居留或变更资格另行判断。

来源：[入管：配偶者申请材料](https://www.moj.go.jp/isa/content/001426540.pdf)、[官方资格一览](https://www.moj.go.jp/isa/applications/status/qaq5.html)。

### 13. 永住者の配偶者等（永住者的配偶者等）

**主要要求**：

- 是永住者或特别永住者的合法配偶，并有真实婚姻生活；或属于其子女在日本出生、出生后持续在日本居留的规定情形。
- 境外出生的孩子不能仅凭父母有永住身份自动适用本类别，应另查定住者等相应路径。
- 证明婚姻或亲子关系、在日生活安排及经费保障；配偶者申请通常由在日配偶担任身元保证人。

**常见材料**：结婚或出生证明、配偶在留身份、住民票、问答书和交流资料、收入纳税证明、身元保证书。

**注意**：本人没有因此取得永住，仍有期限且须续签；在留资格本身没有工作种类限制。

来源：[入管：永住者配偶者等](https://www.moj.go.jp/isa/applications/status/spouseorchildofpermanentresident.html)。

### 14. 定住者（定住者）

**主要要求**：

- 符合定住者告示的具体类别，或有可由法务大臣个别认可的特殊理由，不是希望长期居住就能申请。
- 常见对象有日系3世、中国残留邦人相关人员、符合条件的未成年未婚子女等；须核对亲属、年龄、扶养等具体条件。
- 离婚、丧偶后申请等属于个案判断，不会因曾经结婚自动获得定住者资格。
- 按类别证明身份关系、生活基础、扶养及收入等，部分日系人类别还需无犯罪资料。

**常见材料**：对应类别的户籍、出生与亲属证明、申请理由、经济或扶养资料、身元保证等；个案补充照顾子女及实际居留生活的证明。

**注意**：在留资格本身没有工作种类限制，但有期限，与无期限的永住者不同。

来源：[入管：定住者](https://www.moj.go.jp/isa/applications/status/longtermresident.html)、[外务省：定住者签证](https://www.mofa.go.jp/mofaj/toko/visa/chouki/visa12.html)。

### 15. 永住者（永住者）

**主要要求**：

- 原则上在日本连续居留10年以上，其中连续5年以上持符合规定的工作或居住资格；技能实习、特定技能1号等不能算作这里的合格工作资格年限。
- 原则上品行良好、有独立维持生活的资产或技能，并被认定符合日本利益；日本人、永住者等的配偶或子女对前两项有法定例外，但仍接受国益等审查。
- 按期履行税金、年金、医疗保险和入管申报等公共义务，不能只看申请时是否已经补缴。
- 满足适用的在留期间及其他条件，提交身元保证等资料；不要求必须由配偶或永住者扶养。

**常见年限例外及适用时间**：

| 路线 | 截至本笔记日期适用的主要年限 | 已公布的新安排 |
| :--- | :--- | :--- |
| 日本人、永住者、特别永住者的配偶 | 实质婚姻持续3年以上，并在日本连续居留1年以上 | 2027-04-01起新指南改为婚姻5年以上、在日连续3年以上 |
| 上述人员的实子等 | 在日本连续居留1年以上 | 新指南改为连续3年以上，须核对具体对象 |
| 定住者 | 以定住者资格连续居留5年以上 | 仍须满足其他永住条件 |
| 高度人才70分路线 | 按规定持续满足70分及在日居留3年以上 | 不是仅在申请日达到70分即可 |
| 高度人才80分路线 | 按规定持续满足80分及在日居留1年以上 | 不是仅在申请日达到80分即可 |

**新旧指南的过渡安排**：2026-10-01公布的新指南，原则上自**2027-04-01起的申请**适用；2026-04-01至2027-03-31的申请原则上仍适用2026-02-24版，但收入部分适用新指南对应条款，不能把全部新条件都当作已生效，也不能完全沿用旧收入说法。

- 新收入审查考虑家庭人数对应的日本人家庭平均收入以上的持续收入水平等，不能写成“所有人年薪300万即可”。
- 新指南列入B1相当日语能力、日本制度和规则理解等考量，并有高度人才等例外；按申请日期和实施说明核对，不直接等同于所有人统一考JLPT N3。
- 新指南还涉及退休后的生活保障、在留期间等。以30年厚生年金加入情形作比较的表述，不等于要求所有申请人实际缴费30年；具体应查看完整指南及过渡说明。

**常见材料**：申请表、理由书、家庭住民票、工作及收入资料、规定年度的纳税、年金及医保记录、资产、身元保证等；高度人才路线另交相应时点的积分及持续符合条件的证明。材料及年度范围按申请路线确定。

**获批后**：无在留期间及在留资格上的工作种类限制，但在留卡仍有有效期；暂时离境须办理相应再入境手续，符合条件时可使用视同再入国许可。
