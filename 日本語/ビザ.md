## ビザについて

| 在留資格                 | 説明 |
| :----------------------- | ---- |
| 技術・人文知識・国際業務 | 最も一般的な就労ビザ。日本の企業と雇用契約を結び、エンジニア・デザイナー・翻訳・営業など、専門的な知識や技術を要する業務に従事する外国人に付与される。大卒以上（または同等の実務経験）が要件。在留期間は1年・3年・5年。 |
| 経営・管理               | 日本での事業の経営・管理を行う者に付与されるビザ。資本金500万円以上の会社設立、または事業規模が一定以上であることが要件。事業計画書の提出が必須で、入国管理局による審査が厳しい。在留期間は1年・3年・5年。 |
| 家族滞在                 | 在留資格を持つ外国人の扶養配偶者・子に付与されるビザ。対象は「技術・人文知識・国際業務」「経営・管理」「留学」などの在留資格を持つ者の扶養家族。原則として就労不可（資格外活動許可で週28時間まで可能）。 |
| 技能実習                 | 発展途上国等の外国人を一定期間（最長5年）日本で受け入れ、技術・技能・知識を移転し、各国の経済発展を担う人材を育成する制度。1号（最長1年）・2号（最長2年）・3号（最長2年）に分かれる。受入企業は監理団体を通じて申請。 |
| 特定技能                 | 人手不足が深刻な分野（介護・建設・農業・飲食など14分野）で、即戦力となる外国人材を受け入れる制度。特定技能1号（在留期間通算5年まで・家族同伴不可）と2号（更新可能・家族同伴可）がある。日本語と技能試験の合格が要件。 |
| 特定活動                 | 上記の在留資格に該当しない特別な活動を行う者に付与される。ワーキングホリデー、外交官の家族、特定のインターンシップ、高度外国人材の配偶者など幅広い。活動内容ごとに個別に要件が定められている。 |
| 高度専門職               | 高度な学術研究・技術を持つ外国人を優遇するポイント制ビザ。学歴・職歴・年収などでポイントを加算し、70点以上で認定。在留期間5年、10年後に永住権申請可能（一定条件で1年または3年に短縮）。配偶者の就労制限が緩和される。 |
| 企業内転勤               | 海外の支店・関連会社から日本の支店・子会社へ転勤してくる者に付与される。転勤元で1年以上継続して勤務していることが要件。「技術・人文知識・国際業務」と同じ業務内容に従事可能。在留期間は1年・3年・5年。 |
| 文化活動                 | 日本固有の文化・芸術（日本舞踊・華道・茶道・陶芸など）を習得・研究する活動に従事する者に付与。収入を伴う事業は原則不可。在留期間は6ヶ月・1年・3年。教授や指導者からの推薦状が必要な場合がある。 |
| 留学                     | 日本の大学・短大・専門学校・日本語学校等で教育を受ける者に付与される。週28時間以内のアルバイト（資格外活動）が許可される。在学期间中は在留期間が更新され、卒業後は「技術・人文知識・国際業務」への変更が可能。 |
| 短期滞在                 | 観光・親族訪問・ビジネス視察・会議参加など、短期間の活動に付与される。最長90日間。査証免除協定のある国・地域の国籍者はビザ不要。就労活動（報酬を得る業務）は不可。 |
| 日本人の配偶者           | 日本人と結婚した外国人に付与されるビザ。在留期間の上限なし（1年・3年・5年を更新）。就労制限なし（風俗営業等を除く）。離婚後も一定期間は在留資格を維持できる場合がある。永住権申請の要件も緩和される。 |
| 永住者の配偶者           | 永住者・特別永住者と結婚した外国人に付与されるビザ。就労制限なし。在留期間は1年・3年・5年。日本人の配偶者と同等の扱いを受けるが、永住権申請には別途要件を満たす必要がある。 |
| 定住者                   | 日系人（3世まで）や、中国人残留孤児の家族、日本人の養子など、特別な事情により日本に定住する者に付与される。就労制限なし。在留期間は1年・3年・5年。法務大臣が個別に指定する。 |
| 永住者                   | 在留資格の中で最も自由度が高い。就労制限なし、在留期間の制限なし。原則として10年以上の継続在留が必要（高度専門職は1〜3年）。配偶者または永住者の扶養が必要。素行善良・生計資産要件あり。再入国許可なしで出国すると失効。 |
