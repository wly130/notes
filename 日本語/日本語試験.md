## 日本語能力試験（JLPT）

本笔记整理考试规则、做题方法和备考复盘。原有配速主要对应N2，因此时间分配以N2为示例；其他等级须按各自科目时间调整。

> 规则核对日期：2026-11-03。官方考试时间、合格标准与下文的练习建议分开列出。个人配速和训练量需要通过模拟练习调整，不是官方要求。

### 考试结构与时间

| 等级 | 考试科目及作答时间 | 听力时间 |
| :--- | :--- | :--- |
| N1 | 语言知识（文字、词汇、语法）与阅读：110分钟 | 55分钟 |
| N2 | 语言知识（文字、词汇、语法）与阅读：105分钟 | 50分钟 |
| N3 | 文字、词汇：30分钟；语法与阅读：70分钟 | 40分钟 |
| N4 | 文字、词汇：25分钟；语法与阅读：55分钟 | 35分钟 |
| N5 | 文字、词汇：20分钟；语法与阅读：40分钟 | 30分钟 |

- N1、N2的语言知识与阅读共用一个限时科目，可以在该科目内安排配速。
- N3至N5的文字词汇与语法阅读分为不同科目，不能跨科目自由调配时间。
- 上表为作答时间，不含入场、说明和休息等流程；听力时长可能因录音长度略有变化。
- 不把练习册中的题数当作每次正式考试的固定题数，具体题型按报考等级确认。

来源：[JLPT官方：考试科目、时间与题型](https://www.jlpt.jp/guideline/testsections.html)。

### 合格标准与计分

| 等级 | 总分合格线（满分180） | 各计分区最低要求 |
| :--- | :--- | :--- |
| N1 | 100分 | 语言知识、阅读、听力各19分以上，各区满分60 |
| N2 | 90分 | 语言知识、阅读、听力各19分以上，各区满分60 |
| N3 | 95分 | 语言知识、阅读、听力各19分以上，各区满分60 |
| N4 | 90分 | 语言知识与阅读合计38分以上（满分120）；听力19分以上（满分60） |
| N5 | 80分 | 语言知识与阅读合计38分以上（满分120）；听力19分以上（满分60） |

必须同时达到总分合格线和所有计分区的最低要求，并参加全部规定科目。考试科目的划分与成绩计分区的划分不完全相同。

JLPT使用尺度得分，不是简单按每题固定分值相加；练习正确率可以反映薄弱项，但不能直接换算成正式成绩或据此保证合格。

来源：[JLPT官方：计分区及合格判定](https://www.jlpt.jp/e/guideline/results.html)、[官方常见问题：尺度得分](https://www.jlpt.jp/sp/faq/)。

### 言語知識（语言知识）

#### 文字与词汇

- 读音题注意长短音、促音、浊音和相近读音，不只凭汉字外形判断。
- 根据语境确定词义，结合助词、搭配、语体和感情色彩排除选项。
- 近义表达题比较在当前句子中能否替换，不只看词典中文释义是否相似。
- 用法题检查词语通常搭配什么对象、用于什么情境，避免仅凭汉字意思选择。
- 不同等级还有表记、词语构成等题型，按自己的报考等级补齐练习。
- 对不认识且无法推断的题先作选择并标记，不让单题挤占后续阅读时间。

复习时记录读音、当前语境中的意思及常见搭配，不把所有错误都归为“单词没背够”。

#### 语法形式判断

1. 找出句子主干，确认动作主体、对象及时间关系。
2. 检查空格前后的接续形式，排除语法上不能连接的选项。
3. 比较剩余选项的意义、语气及使用限制。
4. 将答案代入完整句子，检查逻辑是否自然。

接续正确只是必要检查之一，不代表该选项在语境中一定合适。

#### 句子排序

1. 先看横线前后内容，确定整句的结构与大意。
2. 寻找固定搭配、修饰关系、助词和句尾表达。
3. 将四个片段排成语法成立、意思连贯的顺序。
4. 确认星号位置对应哪个片段，再填写该片段的选项编号。
5. 代入整句通读，检查是否有修饰错位或逻辑冲突。

练习时可以记录片段编号；考场上的标记方式须符合当地规定，不预设另有草稿纸。

#### 文章语法

- 先快速了解体裁、人物和话题，再结合空格所在段落逐步判断。
- 同时检查句内接续、前后逻辑、指代、时态和文体的一致性。
- 遇到接续词时，判断是在转折、补充、举例、总结还是承接行动，不把同类中文译义当作完全可互换。
- 指示词可能指一个词、一个事件或前文整段内容；先找候选所指，再代回验证。
- 时态依据叙述时间与上下文关系判断，不能看到过去时间词就认定所有谓语必须用过去式。
- 完成后连读整段，必要时回到全文确认，避免只看空格前一句。

### 読解（阅读）

#### 通用流程

1. 先看问题，明确要找原因、指代、细节、主张还是条件。
2. 带着问题阅读，理解相关段落的完整意思。
3. 在原文中找出判断依据，再比较选项。
4. 核对主语、范围、程度、否定及因果关系。
5. 有争议时回到上下文验证，不凭常识补全作者没有表达的观点。

关注转折和总结能帮助定位，但答案没有固定段落位置。只看关键词、段首或段尾，可能漏掉必要限定。

#### 按题型处理

| 题型 | 处理方法 | 常见失误 |
| :--- | :--- | :--- |
| 短文内容理解 | 明确问题后读完整段，定位细节或理由 | 只读含关键词的一句，漏掉前后限定 |
| 中篇内容理解 | 梳理段落关系，区分观点、解释与例子 | 把举例内容当作作者的最终主张 |
| 长篇内容理解／主张理解 | 先掌握结构，再完整理解与设问相关的论证 | 只看每段首尾，凭位置猜答案 |
| 统合理解（适用等级） | 分别整理各篇观点，再比较共同点和差异 | 将一位作者的观点归给另一位 |
| 信息检索 | 先列出题目条件，再扫描日期、对象、费用及例外 | 找到一个符合项就作答，漏掉其他条件 |

#### 长句拆分

- 先确定句尾谓语，再找主体、对象和修饰成分。
- 将长修饰语与被修饰的名词对应起来。
- 区分作者陈述、引用内容、假设和否定范围。
- 先抓句子骨架，再补充细节；生词影响关键判断时再结合上下文处理。

#### 比较选项

优先检查以下差异：

- **对象改变**：选项中的人物、事物是否与原文一致。
- **范围扩大**：部分情况是否被改写成全部情况。
- **程度加强**：可能、倾向是否被改写成必然。
- **逻辑改变**：原因与结果、目的与手段是否被调换。
- **信息缺失或新增**：是否漏掉限制条件，或加入原文没有的判断。

正确选项可能改述原文；重复了原文词语的选项也可能不符合原意。

### 聴解（听力）

#### 作答原则

- 按正式考试的单次播放流程练习，利用录音中给出的阅读和作答时间；不是完全没有思考时间。
- 先明确问的是谁、什么任务或哪项信息，再听内容。
- 记录与设问有关的关键词，避免抄写整段而漏听后续。
- 留意拒绝、条件变化、修正和最终安排，不仅听开头提出的方案。
- 一题结束后尽快转入下一题，不反复纠结已经错过的信息。

#### 按题型抓重点

| 题型 | 核心任务 | 关注内容 |
| :--- | :--- | :--- |
| 課題理解 | 判断接下来应采取什么行动 | 任务、条件、先后顺序及最终指示 |
| ポイント理解 | 找到设问要求的具体信息 | 人物、原因、时间或其他指定重点 |
| 概要理解 | 理解整体话题、意图或主张 | 对话整体走向及说话者态度 |
| 発話表現（适用等级） | 根据场景选择合适表达 | 双方关系、目的及表达是否适合场合 |
| 即時応答 | 对一句话选择自然回应 | 问句意图、请求、邀请、感叹等语气 |
| 統合理解（N1、N2） | 综合较多信息作判断 | 多方意见、限制条件、比较和最终选择 |

“最后决定”并非所有题目的答案，必须以具体设问为准。

详细精听、泛听、听写与辨音步骤见：[听力练习方法](リスニング.md)。

### 做题节奏

#### N2配速示例

以下为105分钟科目的练习起点，不是官方分段限时。

| 阶段 | 分配时间 | 累计用时 |
| :--- | :--- | :--- |
| 文字与词汇 | 15分钟 | 15分钟 |
| 语法 | 20分钟 | 35分钟 |
| 阅读 | 65分钟 | 100分钟 |
| 检查与填涂核对 | 5分钟 | 105分钟 |

- 在整套模拟中记录实际耗时，再调整分配；阅读耗时较多时，应结合语言知识部分的正确率决定能否压缩时间。
- N1共用科目为110分钟，应另外测定配速，不直接套用N2安排。
- 不要求所有阅读题平均用时相同，按篇幅、题数和难度分配。
- 对明显卡住的题作标记后继续，检查时优先回看有具体疑点的题。
- 填涂应随作答及时核对，不把全部填涂压到最后几分钟。

### 備考方法（备考方法）

#### 先诊断，再分配练习

- 用一套未做过的目标等级材料，按正式科目时间完成。
- 分别记录语言知识、阅读、听力的正确率、耗时和未完成题目。
- 将错误区分为知识不足、理解错误、时间不足和审题失误。
- 优先处理持续失分的计分区，不能只练自己擅长的部分。

#### 阅读精练

1. 限时独立作答，先保留自己的判断。
2. 对照解析，在原文中标出正确答案的依据。
3. 说明错误选项的问题，而不只记答案编号。
4. 拆解影响理解的长句，整理少量高频词汇和语法。
5. 再读文章，检查能否概括主旨与段落关系。
6. 隔几天脱离解析重做，再用新文章检验同类错误是否减少。

练习量以能完成复盘为准，不固定要求每天同时精读多篇短、中、长文。

#### 阅读泛读

- 选择总体能理解的内容，连续阅读，减少逐词查阅。
- 读完概括主题、主要事件或作者观点，检查是否真正理解。
- 将妨碍整体理解的部分挑出精读，不要求所有材料都反复读两遍。

#### 听力专项

- 做题时不看文本，复盘时再分段重听和核对。
- 判断失分来自没听清、词汇语法不懂、处理速度慢，还是遗漏设问。
- 连续重听仍无进展时查看文本找原因，不无限循环。
- 处理后关闭文本、恢复原速重听，再用新材料检验。

#### 一周安排示例

| 练习模块 | 安排原则 | 检查方式 |
| :--- | :--- | :--- |
| 词汇与语法 | 少量新内容配合旧错题复习 | 换语境后仍能判断 |
| 阅读专项 | 轮换练习薄弱题型 | 能找出依据，并解释干扰项 |
| 听力专项 | 做题与精听复盘配套 | 不看文本能理解关键内容 |
| 限时练习 | 定期完成目标科目或整套材料 | 不暂停查词，记录完成度与耗时 |
| 周复盘 | 汇总反复出现的错误 | 明确下一周的一两个改进目标 |

### 错题记录与复习

- 同时复盘“猜对但无法解释”的题，不只收集做错的题。
- 每题保留最关键的依据与改进动作，不必复制整篇解析。
- 先重做旧题确认理解，再用同类新题验证，避免只记住答案。

### 考前检查

- [ ] 已确认报考等级、当地考试通知及准考证要求。
- [ ] 已核对证件、文具、入场时间、考场位置及电子设备规定。
- [ ] 已按正式限时练习，知道各阶段的大致完成节点。
- [ ] 已练习规范填涂，避免题号错位与遗漏。
- [ ] 已复习反复失分的题型和关键知识点。
