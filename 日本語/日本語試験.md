### 言語知識

#### 用时

-   **文字・词汇**（約13题）建议总时间 **10–12分钟**

| 题型     | 题数 | 每题时间 | 技巧       |
| -------- | ---- | -------- | ---------- |
| 汉字读音 | 5题  | 15秒     | 一眼判断   |
| 词义选择 | 5题  | 20秒     | 不会马上跳 |
| 近义词   | 3题  | 25秒     | 看句子语感 |

-   **语法**（約22题）建议总时间 **20–25分钟**

| 题型     | 题数 | 每题时间 | 特点       |
| -------- | ---- | -------- | ---------- |
| 语法选择 | 12题 | 30秒     | 基本语法   |
| 句子排序 | 5题  | 1分钟    | 星号题     |
| 文章语法 | 5题  | 1分钟    | 小短文填空 |

#### 句子排序

1.   **寻找固定搭配和句意逻辑**
2.   **看横线前后的提示**
3.   **做完后一定要带入通读**

-   **先不管 ★，在草稿纸上按顺序排好，最后再看 ★ 位置是谁**

#### 文章语法

-   **不要盲目通读完全文再做题，也不要只看空格那一句**
-   **快速扫视文章的第一段、最后一段以及题目，弄清这篇文章是“随笔”、“商务书信”、“说明文”还是“议论文”，以及作者的基本观点（赞成还是反对）。把握了基调，后面选语气词和接续词时就不容易偏离方向。**
-   **边读边做，锁定空格前后文**
-   **读到空格时，停下来，仔细分析前后两句的逻辑关系（是转折、因果、递进还是举例）**
-   **带入通读，验证逻辑**

>**把前一句简写为“A”，后一句简写为“B”**
>
>-   如果A和B意思是相反的 ➡️ 找**转折**（`ところが`、`とはいえ`、`しかし`）
>-   如果B是对A的总结或结果 ➡️ 找**因果/结论**（`したがって`、`ゆえに`、`そこで`）
>-   如果B是在A的基础上补充新信息 ➡️ 找**递进/并列**（`そのうえ`、`さらに`、`それに`）
>-   如果B是对A的换种说法或解释 ➡️ 找**解释/结论**（`つまり`、`すなわち`、`要するに`）

>   **考察 `これ`、`それ`、`あれ`、`このように`、`そういう` 等**
>
>   -   **90%的答案都在空格的前一句或前半句**。往回看一到两句话，找出那句话的核心名词或核心观点。
>   -   特别注意`これ` 通常指代**刚刚紧接着提到**的事物或作者自己的观点；`それ` 指代**前文提到过**的对方或客观存在的话题。

>   **注意“过去式”与“现在式”的交替**
>
>   -   寻找时间提示词（如 `子供のころ`、`先日` ➡️ 必选 `～た` 形）。
>   -   如果文章整体是在**回忆过去**，突然穿插作者**现在的感想**，句尾往往会切换回现在时（如 `～と思う`、`～なのだ`）。

### 読解

#### 用时

-   建议总时间 **60–65分钟**，平均1题 **1.5分钟**

| 题型     | 数量 | 每篇时间  | 做题方法   |
| -------- | ---- | --------- | ---------- |
| 短篇阅读 | 4篇  | 4–5分钟   | 先看题目   |
| 中篇阅读 | 2篇  | 8分钟     | 找关键词   |
| 长篇阅读 | 1篇  | 12–15分钟 | 看段落结构 |
| 信息检索 | 1篇  | 4分钟     | 表格题     |

-   **遇到不会的词不要停**
-   **长句一定要切分**

#### 短篇阅读

1.   **先看题目**
2.   **找题目关键词**
3.   **回文章定位**

只读 **相关段落**，不要全文读

#### 中篇阅读

-   看 **段落结构**

-   日本文章结构通常是 **问题提出 > 说明 > 举例 > 作者结论**

-   所以,**答案80%在最后一段**

关键词:  **つまり**，**要するに**，**したがって**，**このことから**

#### 长篇阅读

-   **不要**从头逐句翻译
-   只看每段 **第一句** 和 每段 **最后一句**

#### 信息检索

1. **先看问题**
2. **找关键词**
3. **在文章里扫描**

### 聴解

#### 用时

-   固定**50分钟**

-   **只播放一次**
-   **没时间思考**

| 题型         | 特点           | 难度 |
| ------------ | -------------- | ---- |
| 課題理解     | 听对话解决问题 | ⭐⭐   |
| ポイント理解 | 听重点信息     | ⭐⭐   |
| 概要理解     | 听大意         | ⭐⭐⭐  |
| 即時応答     | 快速反应       | ⭐⭐⭐  |
| 統合理解     | 长对话         | ⭐⭐⭐⭐ |

-   **不要听每个词，要听“信息”**

需要听的只有 4 个东西

- **人物关系**（谁在说话）
- **问题是什么**
- **发生什么事情**
- **最后的决定**

### 做题节奏

| 阶段 | 时间   |
| ---- | ------ |
| 词汇 | 10分钟 |
| 语法 | 20分钟 |
| 阅读 | 65分钟 |
| 检查 | 10分钟 |

## 読解練習

### 精読 (每日30分钟-1小时)

每日 **2篇短篇阅读 + 2篇中篇阅读 + 1篇长篇阅读**

1. **先看问题**
2. **带着问题，快速阅读一遍文章，选出答案**
3. **找出不会的单词和语法，进行记忆和理解**
4. **重新阅读一遍文章**

### 泛読 (每日30分钟-1小时)

1.   **找新闻，文章，小说等资源**

2.   **先大概看一遍，理解剧情**

3.   **再完整的看一遍**

## 聴解練習

### 精听 (每日30分钟-1小时)

**第一阶段**

每日听 **30句**

1.   **只听一句话**
2.   **边听边写**
3.   **看原文**
4.   **听不懂的地方，反复的听，直到全部听懂**
5.   **再完整的听一遍句子**

**第二阶段 (第一阶段能够听懂80%以上)**

每日听 **5分钟左右的录音**

1. **听一遍对话或文章，做题**
2. **再听一遍，写关键词**
3. **看原文**
4. **听不懂的地方，反复的听，直到全部听懂，并理解其中的关系和逻辑**
5. **再完整的听一遍对话或文章**

### 泛听 (每日30分钟-1小时)

1.   **找新闻，播客，电视剧，动漫等资源**
2.   **先大概听一遍，理解剧情**
3.   **关闭字幕，再听一遍**

**注意**

-   **认真的听，不要边听边做其他事**
-   **尽量找有日语字幕的资源**
