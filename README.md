## 阅读方式

- 可从本页点击进入对应笔记，也可在本地使用Typora等Markdown编辑器打开。
- 导航使用相对路径，复制或移动仓库时保持目录结构，避免图片和链接失效。
- 部分笔记包含HTML图片标签、iframe或Mermaid图，不同阅读器的支持程度不同；无法显示时可查看源文件或打开对应资源。
- 外部视频、网页和图片链接需要联网，内容可能变更或失效。

## 资源与本地目录

- `img/`保存笔记图片与辅助页面，例如JLPT题型展示HTML；它不仅包含图片文件。
- `履歴書/`是已被`.gitignore`忽略的本地目录，不纳入本页的公开文件导航。
- `.idea/`等编辑器配置目录不属于笔记正文；忽略规则以[.gitignore](.gitignore)为准。

## 维护约定

- 新增笔记优先放入现有主题目录，新增分类或移动文件后同步更新本页导航。
- 保持相对链接有效；移动图片或文档时，一并检查引用位置。
- 对会变化的信息记录适用版本、核对日期及来源，将个人经验与官方规则区分。
- 内容未完成时可保留提纲，避免将计划补充的内容写成已经完成。
