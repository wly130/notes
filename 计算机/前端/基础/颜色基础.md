## 颜色基础

### 三原色

- **红(R)、绿(G)、蓝(B)**
  - **红 + 绿 = 黄**
  - **绿 + 蓝 = 青**
  - **红 + 蓝 = 紫**
  - **红 + 绿 + 蓝 = 白**

### 色彩三要素

| 要素 | 英文 | 说明 |
| :--: | :--: | :--- |
| **色相(H)** | Hue | 颜色的种类（红、黄、蓝等），由光的主波长决定 |
| **饱和度(S)** | Saturation | 颜色的纯度/鲜艳程度，越高越鲜艳，越低越接近灰色 |
| **明度(B/L)** | Brightness/Lightness | 颜色的明暗程度，越高越接近白色，越低越接近黑色 |

### 取色模式

#### RGB模式

> **加色模式**，用于屏幕显示（显示器、手机、电视等）

**rgb(红, 绿, 蓝)**

**范围: 0 ~ 255**

```scss
rgb(0, 0, 0)       // 黑色
rgb(255, 255, 255) // 白色
rgb(255, 0, 0)     // 纯红
rgb(0, 255, 0)     // 纯绿
rgb(0, 0, 255)     // 纯蓝
```

**带透明度：**

```scss
rgba(0, 0, 0, 0.5)     // 50%透明的黑色
rgba(255, 0, 0, 0.8)   // 80%透明的红色
```

#### HSB/HSL模式

> **直觉模式**，更符合人类对颜色的感知方式，设计工具中常用

**HSB(色相, 饱和度, 明度)**

**范围:**

- **H: 0 ~ 360度**（色轮角度：0°=红, 60°=黄, 120°=绿, 180°=青, 240°=蓝, 300°=紫）
- **S: 0 ~ 100%**
- **B: 0 ~ 100%**

```scss
hsl(0, 100%, 50%)    // 纯红
hsl(120, 100%, 50%)  // 纯绿
hsl(240, 100%, 50%)  // 纯蓝
hsl(0, 0%, 0%)       // 黑色
hsl(0, 0%, 100%)     // 白色
```

> **HSB vs HSL**：HSB中B=100%时颜色最亮，HSL中L=50%时颜色最纯。CSS中使用 `hsl()` 为HSL模式。

#### CMYK模式

> **减色模式**，用于印刷输出（打印机、印刷厂等）

**CMYK(青色, 洋红, 黄色, 黑色)**

**范围: 各通道 0% ~ 100%**

| 参数 | 说明 |
| :--: | :--- |
| **C (Cyan)** | 青色，0%~100% |
| **M (Magenta)** | 洋红，0%~100% |
| **Y (Yellow)** | 黄色，0%~100% |
| **K (Key/Black)** | 黑色，0%~100%（增强暗部细节，节省彩色墨水） |

```
C100 M0   Y0   K0    // 纯青
C0   M100 Y0   K0    // 纯洋红
C0   M0   Y100 K0    // 纯黄
C0   M0   Y0   K100  // 纯黑
C100 M100 Y100 K100  // 深黑（四色黑）
```

> **注意**：RGB 色域比 CMYK 广，部分屏幕上的鲜艳颜色印刷后会变暗。设计印刷品时应使用 CMYK 模式以避免色差。

#### Lab模式

> **设备无关模式**，基于人眼视觉感知，涵盖人眼可见的所有颜色

**Lab(亮度, a轴, b轴)**

| 参数 | 范围 | 说明 |
| :--: | :--: | :--- |
| **L (Lightness)** | 0 ~ 100 | 亮度，0=纯黑，100=纯白 |
| **a** | -128 ~ +127 | 绿(-) ← → 红(+) |
| **b** | -128 ~ +127 | 蓝(-) ← → 黄(+) |

```
L50  a0   b0    // 中灰色
L100 a0   b0    // 白色
L0   a0   b0    // 黑色
L50  a80  b0    // 红色
L50  a0   b80   // 黄色
```

**特点**：
- 色域最广，包含 RGB 和 CMYK 的所有颜色
- 与设备无关，不同设备显示一致
- 常用于颜色科学、色彩管理、图像处理的中间转换空间

#### 十六进制模式

> **RGB的简写形式**，前端开发中最常用的颜色表示法

**#红绿蓝**

**范围: 0 ~ 9, A ~ F（每位00~FF，对应十进制0~255）**

```scss
#000000    // 黑色
#FFFFFF    // 白色
#FF0000    // 纯红
#00FF00    // 纯绿
#0000FF    // 纯蓝

// 简写（每位相同时可缩写）
#F00       // 等同于 #FF0000
#0F0       // 等同于 #00FF00

// 带透明度（8位十六进制）
#00000080  // 50%透明的黑色
#FF0000CC  // 80%透明的红色
```

### 色彩心理学

| 颜色 | 心理感受 | 常见应用 |
| :--: | :------- | :------- |
| **红色** | 热情、紧迫、危险、食欲 | 餐饮、促销、警告按钮、错误提示 |
| **橙色** | 活力、友好、温暖、创意 | 儿童产品、食品、CTA按钮 |
| **黄色** | 快乐、警示、注意、乐观 | 警告标志、儿童品牌、 highlight |
| **绿色** | 自然、健康、成功、安全 | 环保、健康产品、成功提示、确认按钮 |
| **蓝色** | 信任、专业、冷静、科技 | 企业官网、社交网络、金融、科技产品 |
| **紫色** | 高贵、神秘、创意、浪漫 | 奢侈品、美妆、创意品牌 |
| **粉色** | 温柔、浪漫、甜美、女性 | 女性产品、母婴、情人节主题 |
| **黑色** | 高端、神秘、权威、简约 | 奢侈品、高端品牌、暗黑模式 |
| **白色** | 纯净、简洁、空间、现代 | 极简设计、医疗、苹果风格 |
| **灰色** | 中立、专业、低调、平衡 | 背景色、辅助文字、商务风格 |

### 配色原则

| 原则 | 说明 |
| :--- | :--- |
| **60-30-10 法则** | 主色占60%（背景/大面积）、辅色占30%（次要元素）、强调色占10%（按钮/链接/CTA） |
| **对比度** | 文字与背景对比度至少 4.5:1（WCAG AA标准），大文字至少 3:1 |
| **色彩数量** | 同一界面主色不超过3种，避免视觉混乱 |
| **一致性** | 相同功能的元素使用相同颜色（如所有链接同一颜色、所有错误提示同一颜色） |
| **无障碍** | 不仅靠颜色传达信息，需配合图标/文字（考虑色盲用户） |

### 常见配色方案

| 方案 | 说明 | 示例 |
| :--- | :--- | :--- |
| **单色** | 同一色相的不同明度/饱和度 | 深蓝→中蓝→浅蓝 |
| **互补色** | 色轮对角的两色 | 蓝 + 橙、红 + 绿 |
| **类似色** | 色轮上相邻的2~3色 | 蓝 + 蓝绿 + 绿 |
| **分裂互补** | 一色 + 其互补色的两侧邻色 | 蓝 + 黄橙 + 红橙 |
| **三角配色** | 色轮上等距的3色 | 红 + 黄 + 蓝 |
