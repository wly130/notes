## UI设计基础

### 设计原则

| 原则 | 说明 |
| :--: | :--- |
| **一致性** | 同一产品中的颜色、字体、间距、交互方式应保持统一，降低用户学习成本 |
| **对比** | 通过大小、颜色、粗细等差异突出层次，引导用户视觉焦点 |
| **对齐** | 元素之间保持对齐关系（左对齐/居中/右对齐），使页面整洁有序 |
| **亲密性** | 相关内容在空间上靠近，不相关内容拉开距离，形成清晰的信息分组 |
| **留白** | 适当留白让界面呼吸，避免信息过载，提升可读性和高级感 |
| **反馈** | 用户每个操作都应有明确反馈（点击变色、加载动画、成功/失败提示） |

### 排版规范

| 要素 | 建议 |
| :--: | :--- |
| **字体选择** | 中文：思源黑体/苹方/微软雅黑；英文：Roboto/Inter/SF Pro；代码：Fira Code/JetBrains Mono |
| **字号层级** | 标题 24~32px → 副标题 18~20px → 正文 14~16px → 辅助文字 12px |
| **行高** | 正文行高 = 字号 × 1.5~1.8（如16px正文，行高24~28px） |
| **字间距** | 中文默认，英文适当增加 letter-spacing: 0.5~1px |
| **段落间距** | 段落间使用 margin-bottom: 16~24px 分隔 |
| **单行字数** | 中文正文每行建议 30~40 字，英文 60~80 字符，过长影响阅读 |

### 设计风格

#### Flat Design (扁平化设计)

<img src="https://pic2.zhimg.com/80/ccdc1e0be2ea39a058c339299a3f38c7_720w.jpg" style="margin:0;" />

- **定义**：去除多余的装饰效果（阴影、渐变、纹理），使用简洁的色块、图标和排版来传达信息
- **核心特征**：
  - 无拟真效果（无阴影、无渐变、无高光）
  - 大面积纯色色块
  - 简洁的图标和排版
  - 明亮的配色方案
- **优点**：加载快、适配多端、开发成本低、信息传达高效
- **缺点**：元素层级不够明显、可点击区域不够直观
- **适用场景**：移动端APP、后台管理系统、信息展示类网站
- **代表**：Microsoft Metro UI、Windows 8/10、早期 iOS 7+

#### Material Design (卡片化设计)

<img src="https://pic3.zhimg.com/80/f820d6c83de99fa2cf592c044cc3ba4a_720w.jpg" style="margin:0;" />

- **定义**：Google 于2014年发布的设计语言，融合了扁平化与拟物化的优点，通过"纸张层叠"隐喻建立视觉层级
- **核心特征**：
  - 卡片式布局，元素像纸张一样层叠
  - 柔和的投影表现层级关系
  - 大胆的色彩搭配
  - 流畅的过渡动画（涟漪效果）
  - 基于网格的响应式布局
- **优点**：层级清晰、跨平台一致、交互反馈明确、文档完善
- **缺点**：设计规则较多、风格趋同、创意受限
- **适用场景**：Android应用、Google系产品、跨平台Web应用
- **代表**：Google 全家桶、Android 系统、Angular Material

#### Neumorphic Design (新拟物设计)

<img src="https://pic2.zhimg.com/80/v2-05b84f8ec0eaa2648b2101ead3810249_720w.jpg?source=1940ef5c" style="margin:0;" />

- **定义**：2020年兴起的设计风格，通过柔和的内外阴影创造出元素从背景"挤出"的立体效果，介于扁平与拟物之间
- **核心特征**：
  - 元素与背景同色系
  - 柔和的双层阴影（左上亮、右下暗）
  - 圆润的边角
  - 极简的配色（通常单色系）
- **优点**：视觉柔和、现代感强、视觉吸引力高
- **缺点**：对比度低、可访问性差（视障用户难辨）、开发成本高、不适合复杂界面
- **适用场景**：概念设计、小型组件/控件、音乐播放器、天气APP
- **代表**：Dribbble 概念作品、部分音乐/天气类APP

#### Skeuomorphic Design (拟真化设计)

<img src="https://pica.zhimg.com/80/v2-dd70bea1b59c36a25024ad1c0dc32d6b_720w.jpg?source=1940ef5c" style="margin:0;" />

- **定义**：模仿真实世界物体的材质、纹理和形态，让用户通过现实经验理解数字界面
- **核心特征**：
  - 逼真的材质纹理（木纹、皮革、金属）
  - 丰富的阴影和高光
  - 渐变色彩
  - 模拟物理按钮/开关的交互
- **优点**：直觉化、降低学习成本、视觉丰富
- **缺点**：开发成本高、文件体积大、难以适配多端、设计维护困难
- **适用场景**：游戏界面、音乐/乐器类APP、儿童教育产品
- **代表**：iOS 6 及之前版本、早期 Kindle、GarageBand

#### Minimalist Design (极简主义设计)

- **定义**：以"少即是多"为核心理念，去除一切非必要的视觉元素，只保留最核心的内容和功能
- **核心特征**：
  - 大量留白
  - 极少的色彩（通常黑白灰 + 1个强调色）
  - 精简的文字和图标
  - 无多余装饰
- **优点**：聚焦内容、高级感强、加载极快、不易过时
- **缺点**：信息密度低、功能表达受限、对排版要求极高
- **适用场景**：品牌官网、作品集、高端产品页、艺术展览
- **代表**：Apple 官网、无印良品、Medium

#### Glassmorphism (玻璃拟态设计)

- **定义**：通过半透明模糊效果模拟毛玻璃质感，创造出深度和层次感
- **核心特征**：
  - 半透明背景 + 背景模糊（backdrop-filter: blur）
  - 细边框（1px 白色半透明边框）
  - 柔和的阴影
  - 鲜艳的渐变背景
- **优点**：视觉层次清晰、现代感强、通透轻盈
- **缺点**：对比度可能不足、性能消耗（模糊效果）、对背景图有依赖
- **适用场景**：卡片组件、弹窗/浮层、仪表盘、iOS/macOS 界面
- **代表**：macOS Big Sur、iOS 7+ 控制中心、Windows 11 Fluent Design

#### Dark Mode (暗黑模式)

- **定义**：以深色/黑色为背景、浅色文字为前景的界面主题，减少屏幕对眼睛的刺激
- **核心特征**：
  - 深灰/纯黑背景（#121212 ~ #1E1E1E）
  - 降低文字对比度（避免纯白，使用 #E0E0E0 等）
  - 强调色饱和度适当降低
  - 阴影用更深的颜色代替
- **优点**：护眼（低光环境）、省电（OLED屏）、视觉高级感、减少蓝光
- **缺点**：设计难度高（对比度把控）、亮暗模式需同时维护
- **适用场景**：所有类型应用（作为可选主题）、视频/音乐类APP、代码编辑器
- **代表**：GitHub Dark、VS Code Dark、Twitter/X

### 配色建议

| 配色方案 | 说明 | 适用场景 |
| :------- | :--- | :------- |
| **单色配色** | 同一色相的不同明度/饱和度变化 | 简洁风格、品牌一致性强的产品 |
| **互补色** | 色轮上对角位置的两色（如蓝+橙） | 需要强烈对比和视觉冲击的场景 |
| **类似色** | 色轮上相邻的2~3种颜色 | 和谐统一、视觉舒适的界面 |
| **三色组** | 色轮上等距的3种颜色 | 活泼多彩、儿童/娱乐类产品 |
| **60-30-10法则** | 主色60% + 辅色30% + 强调色10% | 通用配色比例，保持视觉平衡 |
