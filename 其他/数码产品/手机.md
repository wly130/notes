## 手机

手机选购先看常用应用、通信和使用习惯，再比较硬件。相同品牌不同价位、代际和销售地区的机型差异可能很大，不能只按品牌或单个参数判断。

> 整理日期：2026-11-03。本文以基础知识与选购方法为主，不列实时价格或具体机型排名。系统支持、应用兼容、通信功能与售后政策，以目标机型、地区和购买时的官方说明为准。

### 品牌与生态

| 品牌 | 了解重点 |
| :--- | :--- |
| Apple | iOS应用、与其他Apple设备协同、存储容量、维修成本及地区版本 |
| 三星 | 具体机型的系统支持、屏幕、相机、折叠结构及本地服务适配 |
| 小米 | 具体机型的性能、影像、系统功能及与已有设备的协同 |
| vivo／iQOO | 不同系列的性能、影像、续航取向及系统体验 |
| OPPO／一加／realme | 各品牌及机型的实际系统、售后、充电协议和产品定位 |
| 华为 | 具体HarmonyOS版本、必需应用及配件兼容情况、通信与维修支持 |
| 荣耀 | 具体系统版本、跨设备协同、续航、影像和售后 |
| 摩托罗拉 | 本地在售版本、更新政策、网络频段及维修渠道 |
| Google Pixel | 销售与售后地区、Google服务依赖、运营商支持及应用兼容 |
| 索尼 | 销售地区、更新承诺、相机操作方式、网络适配和维修渠道 |

这些是比较维度，不是品牌优劣排名。手表、耳机、车机、门禁和电脑协同都应实际验证，不能只凭“同品牌”判断全部兼容。

### 系统

| 系统 | 基本认识 | 购买前检查 |
| :--- | :--- | :--- |
| iOS | Apple手机系统，应用、权限及设备协同由其生态规则管理 | 常用应用、文件传输、订阅、配件和地区功能 |
| Android | 多家厂商采用的系统基础，界面、服务和更新由具体厂商及机型决定 | 官方更新承诺、后台管理、通知、应用安装及本地服务 |
| HarmonyOS | 必须结合具体代际和机型理解应用生态 | 必需应用的实际版本、登录、支付、外设及数据迁移 |
| Windows 10 Mobile | 已终止支持的历史手机系统 | 仅作旧设备知识，不作为新购主力机的常规选项 |

- 系统大版本更新、安全补丁和应用更新是不同事项，不能只看版本号是否较新。
- Android机型的更新到达时间和支持周期并不统一，应核对具体型号及地区。
- 不把不同代际HarmonyOS的应用兼容性混为一谈。能安装、能启动、能完整使用并不是同一回事。
- 跨系统换机时，聊天记录、付费应用、游戏角色、票卡和密码管理数据未必能直接迁移。

来源：[Google：检查和更新Android](https://support.google.com/android/answer/7680439?hl=zh-Hans)、[华为：HarmonyOS支持](https://consumer.huawei.com/cn/support/harmonyos/)、[Microsoft：停止支持的系统说明](https://support.microsoft.com/zh-tw/windows/deployment/updates-lifecycle/what-does-it-mean-if-windows-isn-t-supported)。

### 核心硬件参数

#### 处理器与性能

| 项目 | 影响 | 如何判断 |
| :--- | :--- | :--- |
| CPU | 应用启动、计算、多任务中的部分表现 | 结合实际应用，不能只比核心数量和频率 |
| GPU | 游戏图形、部分影像与计算工作 | 看目标游戏的画质、帧率及长时间稳定性 |
| ISP | 相机图像处理链路中的一部分 | 与传感器、镜头和软件共同看，不能单独决定成像 |
| NPU等AI加速单元 | 部分本地智能功能 | 看具体功能是否本地运行、是否支持当前语言及地区 |
| 调制解调器与射频系统 | 通信、弱信号表现及部分功耗 | 看频段、运营商支持和实际使用地点 |
| 散热与功耗控制 | 持续性能、机身温度、续航 | 长时间测试比单次峰值跑分更有参考价值 |

“旗舰芯片”不等于任何机身都能持续满速运行。体积、散热、系统调度、环境温度和游戏版本会共同影响体验。

#### 运行内存与存储

- **运行内存（RAM）**：用于正在运行的应用；影响多任务，但后台保留也受系统策略影响。
- **存储容量**：保存系统、应用、照片、视频和下载文件；标称容量不等于用户可用容量。
- **内存扩展**：利用存储等机制辅助内存管理，不等同于增加同容量物理RAM。
- **存储速度**：影响安装、大文件传输等，但具体表现还受处理器、温度和剩余空间影响。
- 不同系统的内存管理不同，不直接按RAM数字跨系统判断流畅程度。

容量选择可先查看旧机实际占用，再考虑预计使用年限及增长：

| 使用情况 | 容量规划方法 |
| :--- | :--- |
| 社交、支付、轻量使用 | 统计应用和聊天缓存，并留出更新与临时文件余量 |
| 多款大型游戏 | 按游戏完整资源包及后续更新计算，不只看安装包大小 |
| 经常拍视频、存离线内容 | 结合每月增长量估算，并明确导出与备份频率 |
| 计划长期使用 | 同时考虑未来增长和更大容量版本的差价 |

云空间能辅助归档，但不等于所有应用都能移出本机，也不保证所有数据都已备份。

#### 屏幕

| 参数 | 含义与取舍 |
| :--- | :--- |
| 尺寸与比例 | 影响内容面积、握持和横屏使用，结合机身宽度体验 |
| 分辨率与像素密度 | 影响细腻程度，也受观看距离、排列及渲染影响 |
| 刷新率 | 影响滚动和动画流畅度，实际应用未必始终运行在最高值 |
| 触控采样率 | 与触控响应有关，不等于屏幕刷新率或游戏帧率 |
| 亮度 | 区分全屏、局部峰值、手动及自动条件，不能只比最高数字 |
| 色彩与色准 | 关注显示模式及内容管理，不把鲜艳等同于准确 |
| OLED／LCD | 显示原理不同，实际素质仍看具体面板、调校及使用场景 |
| 调光方式 | 不只看宣传频率；可在常用亮度下体验观感，避免仅凭标签下结论 |
| 直屏／曲面屏 | 比较握持、边缘误触、贴膜及维修成本 |

折叠机还应检查外屏可用性、展开重量、折痕观感、铰链与内屏维修费用；不要只比较展开后的屏幕大小。

### 影像能力

#### 先分清各镜头

- **主摄**：多数日常照片的主要来源，优先检查常用场景下的实际表现。
- **超广角**：适合容纳更大场景，注意边缘画质、畸变和暗光表现。
- **长焦**：适合远处细节和不同构图；“潜望式”描述结构，不自动代表更高画质。
- **微距**：关注最近对焦距离及实际细节，不以镜头数量判断价值。
- **前置**：自拍、视频通话、对焦能力和不同应用中的调用效果都要检查。

#### 参数与实际效果

| 项目 | 正确理解 |
| :--- | :--- |
| 像素数 | 影响采样与裁切空间，不能单独决定清晰度和夜景质量 |
| 传感器尺寸 | 是重要因素，还需结合镜头、曝光、读出和算法 |
| 光圈 | 影响进光与景深；跨机型比较还要考虑画幅和实际拍摄条件 |
| OIS | 光学防抖有助于减轻手抖，不能冻结被摄对象运动 |
| EIS | 电子防抖常依赖裁切与算法，关注视角变化和画面拉扯 |
| 光学／裁切／数码变焦 | 原理不同，倍率标签不能替代同一倍率下的实际比较 |
| 夜景与HDR | 可能进行多帧合成，注意运动模糊、重影及处理风格 |
| 人像模式 | 检查头发、眼镜和复杂边缘，背景虚化不一定来自光学景深 |

#### 试拍方法

1. 在相近光线、相同取景和倍率下比较，关闭不需要的美颜或滤镜。
2. 分别拍静物、运动人物、逆光、室内和远处文字。
3. 检查快门响应、对焦成功率、肤色及不同镜头间的一致性。
4. 拍一段移动视频，检查防抖、对焦、收音、镜头切换与发热。
5. 导出原文件比较，避免只看社交平台压缩图或展示机屏幕。

### 电池与充电

- 电池容量不能单独代表续航；屏幕、芯片、信号、应用、温度和电池老化都会影响耗电。
- 不同电压和电芯方案的产品，单看mAh不一定能准确比较能量；有条件时结合Wh及同场景测试。
- 宣传充电功率通常是特定条件下的峰值，不代表全程都以该功率充电。
- 充电器、线材、手机和协议须共同匹配；同为USB-C接口不代表支持同一种快充。
- 看完整充电曲线、常用电量区间的补电时间和温度，而不只看峰值瓦数。
- 无线充电还受对位、保护壳、协议和散热影响，使用便利与发热需要一起考虑。

日常以避免高温和异常发热为重点，不必为了固定电量区间频繁干预充电。按设备提供的优化充电或充电上限功能设置即可，也不需要定期彻底放电。

Apple对iPhone明确提示避免在高于35°C的环境使用或充电；其他设备按自身说明书执行，不能把该温度当成所有电池的统一标准。[Apple：电池充电与维护](https://support.apple.com/zh-cn/105105)。

### 通信、接口与功能

| 功能 | 购买前核对 |
| :--- | :--- |
| 蜂窝网络 | 具体型号频段、当地运营商、VoLTE／VoWiFi等支持情况 |
| 双卡／eSIM | 卡槽组合、同时启用限制、运营商及地区办理条件 |
| Wi-Fi | 手机、路由器、频段与当地法规共同影响实际能力 |
| 蓝牙音频 | 手机与耳机须共同支持相应编码，实际延迟还看软件链路 |
| NFC | 有NFC不等于支持所有门禁、公交、银行卡和车钥匙 |
| 定位 | 结合城市遮挡、导航软件和实际场景，不只看卫星系统数量 |
| USB-C | 分别检查充电、数据速率、视频输出及外设能力 |
| 生物识别 | 检查暗光、湿手等常用场景，以及支付应用的实际支持 |
| 卫星通信等特殊功能 | 具体服务、覆盖、开通、费用及紧急用途限制 |
| 防尘抗水 | 按机型测试条件理解，不视为可长期浸水或水下拍摄保证 |

USB-C是接口形态，不能据此推断一定有高速传输或视频输出。[USB-IF：Type-C接口与USB 2.0说明](https://www.usb.org/sites/default/files/usb_type-c_language_product_and_packaging_guidelines_20230320.pdf)。

抗水能力可能因磨损、跌落及维修而下降；不要主动用进水来验机，进液后的保修也须查看具体条款。[Apple：防溅、抗水和防尘说明](https://support.apple.com/zh-cn/108039)。

### 按需求筛选

| 主要需求 | 优先比较 | 容易忽略 |
| :--- | :--- | :--- |
| 日常通勤 | 握持、亮度、信号、续航与系统便利 | 重量、振动、扬声器及误触 |
| 长时间游戏 | 持续帧率、散热、触控、续航 | 充电时温度、游戏适配和网络 |
| 拍照录像 | 常用焦段、运动成片率、收音、防抖 | 存储增长、导出速度和应用压缩 |
| 工作与学习 | 必需应用、通知、文档、权限及协同 | 企业管理、双卡和跨平台数据 |
| 长辈使用 | 字体、音量、简单操作、服务网点 | 广告干扰、支付确认和远程协助 |
| 经常出差 | 频段、漫游、双卡、eSIM与导航 | 地区服务、保修及语言支持 |

先列三项必需功能及可接受的尺寸重量，再定总预算。总成本还应包含配件、云空间、保障服务和可能的电池或屏幕维修。

### 新机与二手验机

#### 新机

- 核对型号、容量、颜色、地区版本、发票和售后渠道。
- 按正常流程检查外观、屏幕、触控、扬声器、麦克风、相机、按键与充电。
- 插卡测试通话、移动数据和常用网络，检查Wi-Fi、蓝牙及定位。
- 使用纯色画面辅助检查明显坏点和异常，但不以极端曝光照片中的细小差异直接判断正常使用故障。
- 保留包装及购买凭证，退换和激活要求以购买渠道实际规则为准。

#### 二手

- 核对卖家身份、来源凭证、维修及进液记录；序列号查询不能证明所有零件均为原装。
- 检查屏幕、镜头、接口、机身变形及生物识别功能。
- 查看可用的电池与维修提示，并结合实际续航；单个“健康度”数字不能概括整机状态。
- 确认账号锁、查找功能、企业管理或分期限制已合法解除，并能完成重置后的正常激活。
- 以平台规则和书面约定明确验机、退货及保修，避免仅凭口头“无拆修”保证。

### 换机、备份与隐私

1. 先备份照片、联系人、文档和聊天记录，确认恢复方法。
2. 单独处理身份验证器、恢复码、银行应用、票卡和工作应用。
3. 在新设备验证登录、通知、支付和重要文件，再清理旧设备。
4. 旧机退出个人账号，解除配对及查找绑定，按官方流程抹掉数据。
5. 移除实体SIM及存储卡；使用eSIM时按运营商和系统流程迁移、删除配置。

云同步不等于独立备份：同步删除可能传播到其他设备，重要文件应另留一份可恢复副本。不要在仍与云端同步的旧手机上逐项手动删除资料来代替完整抹掉。

来源：[Apple：出售或转让设备前的处理](https://support.apple.com/zh-cn/109511)。其他品牌按对应官方换机和重置流程操作。

### 使用维护与常见问题

完整维护方法见：[数码产品保养](保养.md)。

| 问题 | 先检查什么 |
| :--- | :--- |
| 续航突然下降 | 电池用量、弱信号、导航或热点、近期更新及异常后台应用 |
| 发热与性能下降 | 环境、充电、游戏画质、恢复备份及持续高负载 |
| 存储不足 | 聊天附件、离线资源、视频及可安全清理的缓存，先备份后删除 |
| 通知延迟 | 通知权限、后台与省电策略、网络及应用自身设置 |
| 充电慢 | 适配器、线材、协议、接口状态、电量区间和温度 |
| 照片模糊 | 镜片污渍、对焦、拍摄距离、手抖及被摄体运动 |
| 信号异常 | 覆盖、SIM、运营商设置、地区版本与其他设备对比 |

先记录触发条件并排查设置，不把恢复出厂当作第一步。持续异常或电池鼓包等硬件问题应停止相关使用并联系正规维修。

### 购买检查清单

- [ ] 必需应用及外设能正常使用。

- [ ] 容量覆盖当前占用与预计增长。
- [ ] 通信、SIM及地区功能符合需求。
- [ ] 关注过持续性能、续航和常用场景影像表现。
