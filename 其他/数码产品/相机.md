## 相机

相机选购应从拍摄对象、携带方式和照片或视频的最终用途出发，再考虑机身、镜头和配件。镜头、光线、拍摄方法与后期流程都会影响结果，机身价格和像素数不能单独代表成片质量。

> 整理日期：2026-11-03。本文侧重基础知识、选购和实际操作，不列实时价格或机型排名。卡口兼容、视频规格、配件与固件功能，以具体产品的官方说明书为准。

### 品牌与系统

| 品牌 | 常见系统或产品方向 | 了解重点 |
| :--- | :--- | :--- |
| 索尼 | E卡口可换镜头系统及固定镜头相机 | 镜头覆盖画幅、机身操作、对焦及视频组合 |
| 佳能 | RF系统及其他新旧卡口设备 | RF／RF-S、EF／EF-S、EF-M的区别及转接限制 |
| 尼康 | Z系统及F卡口设备 | 全画幅／DX镜头覆盖、转接与对焦兼容 |
| 富士 | X系统与GFX系统 | 两套卡口不同，镜头和画幅不能混为一谈 |
| 松下 | L卡口与Micro Four Thirds系统 | 先区分具体系统，再看视频、对焦及镜头 |
| OM SYSTEM／奥林巴斯 | Micro Four Thirds系统及其他产品 | 卡口、机身镜头协同和具体防护条件 |
| 理光／宾得 | 固定镜头便携机及单反等产品 | 固定镜头使用习惯或可换镜头系统的长期投入 |
| 徕卡 | 多种卡口与固定镜头系统 | 各产品线差异、操作方式与总体成本 |
| DJI／GoPro等 | 运动、手持或其他专门视频设备 | 防抖、视角、收音、续航与使用环境 |

品牌内部也有不同卡口和定位。先选适合自己的系统，再比较具体机型，不以“某品牌只适合照片或视频”概括全部产品。

### 相机类型

| 类型 | 特点 | 适合关注的需求 | 主要取舍 |
| :--- | :--- | :--- | :--- |
| 手机 | 便携，计算摄影和分享流程方便 | 日常记录、轻量视频 | 光学焦段、操作和附件受限，具体表现看机型 |
| 固定镜头便携相机 | 镜头不可更换，大小和焦段差异较大 | 随身拍摄、旅行 | 需接受固定焦距或变焦范围 |
| 无反相机 | 无反光镜结构，电子取景或屏幕取景 | 可换镜头摄影及视频 | 考虑镜头体积、电池、热管理和操作 |
| 单反相机 | 反光镜与光学取景结构 | 已有镜头或偏好光学取景 | 新旧系统、维修与视频能力要具体检查 |
| 运动相机 | 通常小巧、广视角，强调固定方式 | 运动记录、特殊机位 | 暗光、视角、收音及保护壳条件 |
| 手持云台相机 | 机械云台与相机整合 | 行走记录、轻便视频 | 云台活动范围、抗冲击和附件限制 |
| 胶片相机 | 使用胶片，冲洗扫描后得到影像 | 胶片流程体验 | 胶卷、冲扫、测光和维修持续成本 |

“微单”常被用来指无反相机，不代表所有无反都小巧。套机是否轻便，要连同镜头、电池和附件一起计算。

### 画幅、像素与画质

#### 画幅

| 画幅 | 大致认识 | 比较时注意 |
| :--- | :--- | :--- |
| 中画幅数码 | 传感器通常大于35mm全画幅，尺寸并不统一 | 机身镜头体积、预算、对焦速度及实际需求 |
| 全画幅 | 通常约36×24mm | 综合能力与镜头成本、重量之间的取舍 |
| APS-C | 比全画幅小，不同厂商尺寸略有差异 | 常见视角换算约1.5倍，佳能部分系统约1.6倍 |
| Micro Four Thirds | 常见尺寸约17.3×13mm，视角换算约2倍 | 系统体积、镜头焦段、景深及暗光表现 |
| 1英寸型及更小规格 | 常见于部分便携机等设备 | “英寸型”是历史规格名称，不是实际对角线长度 |

- 相同构图与输出要求下，画幅会影响镜头选择、景深和弱光表现，但不能脱离镜头、技术代际及曝光条件判断。
- 大画幅并不自动带来更好的构图或更高的拍摄成功率。
- “全画幅镜头”描述覆盖范围，不代表装在较小画幅机身上就会使用整个成像范围。

#### 像素与其他因素

- 高像素能提供更多细节采样和裁切空间，但需要镜头、对焦、快门和支撑配合。
- 不同像素数比较噪点时，结合相同输出尺寸，避免只在100%放大下下结论。
- 动态范围关系到可保留的亮暗层次，仍需控制曝光，不能指望后期恢复已经完全丢失的细节。
- 传感器读出速度影响电子快门变形、连拍及部分视频表现，不由像素数单独决定。
- 颜色风格与色彩准确性是不同维度；白平衡、光源、显示器和后期都会影响观感。

### 镜头与卡口

#### 卡口兼容

| 项目 | 需要核对 |
| :--- | :--- |
| 机械卡口 | 能否直接安装，不能仅看品牌相同 |
| 镜头覆盖画幅 | 是否覆盖传感器，是否触发裁切或出现暗角 |
| 自动对焦 | 机身、镜头、转接环与固件组合是否支持所需功能 |
| 防抖与光圈控制 | 是否支持协同、电子控制或仅能手动操作 |
| 转接 | 法兰距、电子协议、机械干涉及厂商兼容表 |
| 视频操作 | 对焦噪声、呼吸效应、变焦和光圈变化是否符合需求 |

索尼E系统中的FE通常指覆盖全画幅的镜头；佳能RF-S、尼康DX等标识涉及画幅覆盖。富士X与GFX、松下L卡口与Micro Four Thirds不是同一卡口，不能直接互换。

购买第三方镜头或转接环时，查清准确型号与固件兼容性，不把“能装上”当作功能完整兼容。

#### 焦距与视角

- 焦距是镜头的物理参数，安装在不同画幅上不会改变其真实焦距。
- 等效焦距用于比较视角，常用计算为：**实际焦距 × 画幅换算系数**。
- 例如35mm镜头装在1.5倍APS-C机身上，视角约相当于全画幅52.5mm，镜头本身仍为35mm。
- 同一拍摄位置下换焦距主要改变取景范围；透视关系主要由拍摄位置决定。为保持主体大小而移动位置时，透视也会改变。

| 视角类别 | 常见用途 | 注意点 |
| :--- | :--- | :--- |
| 广角 | 风景、建筑、环境记录 | 边缘拉伸、构图杂乱及近距离透视效果 |
| 标准 | 日常、人文、环境人像 | 取景自然与否还取决于位置和观看方式 |
| 中长焦 | 人像、舞台、局部景物 | 拍摄距离、快门、稳定和携带成本 |
| 超长焦 | 鸟类、野生动物、远处运动 | 寻找主体、空气扰动和支撑要求 |
| 微距 | 小物、昆虫、细节 | 放大倍率、工作距离、景深和补光 |

#### 定焦与变焦

- **定焦**：焦距固定，部分产品可兼顾较大光圈或较轻体积，但不是所有定焦都小巧或画质更好。
- **变焦**：便于快速改变取景，注意体积、最大光圈、最近对焦距离及边缘表现。
- **恒定光圈变焦**：变焦时最大可用光圈值保持不变，不等于画面亮度在所有条件下绝对不变。
- **可变最大光圈变焦**：变焦时最大可用光圈可能缩小，拍视频时需注意曝光变化。
- 第一支镜头优先覆盖常拍题材和携带需求，使用一段时间后再根据实际缺口补充。

来源：[佳能：镜头基础知识](https://www.canon.com.cn/special/rflensworld/knowledge/)、[佳能说明书：全画幅与APS-C裁切示例](https://cam.start.canon/zh/C003/manual/html/UG-03_Shooting-1_0050.html)。

### 曝光与景深

#### 光圈、快门与ISO

| 参数 | 对画面的作用 | 常见误区 |
| :--- | :--- | :--- |
| 光圈 | 控制进光开口，影响景深和镜头表现 | f值越小通常表示光圈越大，不是数字越大进光越多 |
| 快门时间 | 决定曝光持续时间，影响运动模糊和手抖 | 防抖不能代替冻结运动所需的快门 |
| ISO | 在相机成像流程中影响亮度与噪点等表现 | 提高ISO不会让镜头实际接收更多光线 |

- 在其他条件相同时，光圈和曝光时间共同影响传感器接收的光量；ISO与输出亮度、处理和相机实现有关。
- 一档变化常表示两倍或一半的关系。例如曝光时间从1/125秒变为1/250秒，曝光时间约减半。
- 景深还受焦距、对焦距离、画幅及观看条件影响，不能只看光圈值。
- 极小光圈可能受到衍射影响，不是光圈越小整张照片就一定越清晰。
- 光线不足时，应在运动清晰度、景深和噪点之间取舍，不为追求最低ISO而拍出模糊照片。

#### 常用拍摄模式

| 模式 | 主要控制 | 适用思路 |
| :--- | :--- | :--- |
| 自动 | 相机决定多数参数 | 快速记录，先关注取景与时机 |
| P | 相机配合曝光参数，允许部分调整 | 希望方便拍摄，同时控制部分设置 |
| A／Av | 用户选光圈，相机计算其他曝光参数 | 控制景深，同时监测快门是否过慢 |
| S／Tv | 用户选快门，相机计算其他曝光参数 | 控制运动表现，注意光圈及ISO是否到达限制 |
| M | 用户选光圈与快门 | 稳定光线、闪光或需要固定参数的场景 |

M模式配自动ISO时，画面亮度仍可能由相机自动调整；曝光补偿是否可用及如何工作看机型。曝光补偿用于调整自动曝光目标，不是后期亮度滑块。

#### 测光、白平衡与曝光检查

- 测光是相机对场景亮度的判断，明亮或深暗主体可能需要结合意图调整曝光。
- 白平衡用于处理光源色偏，自动、预设或自定义方式各有适用场景。
- 查看直方图和高光警告，结合关键主体判断是否过曝；直方图偏左或偏右不自动代表错误。
- 机内预览与直方图常受JPEG处理影响，不完全等同于RAW的全部可恢复范围。
- 混合光源难以仅靠一个白平衡值统一，必要时改变位置、光源或后期局部处理。

来源：[Sony：光圈及A模式](https://www.sony.com/zh-cn/electronics/support/compact-cameras-zv-series/zv-1/articles/00243684)、[佳能：摄影关键词](https://www.canon.com.cn/special/ds_abcbook/keyword.html)。

### 对焦、连拍与防抖

- **单次对焦**：适合相对静止的主体；对焦后主体或机位变化仍可能失焦。
- **连续对焦**：用于持续移动的对象，需结合跟踪区域、主体识别和镜头响应。
- **人眼／动物／车辆等识别**：仅是辅助功能，支持对象和表现因机型、模式及固件而异。
- **单点与区域对焦**：前者便于指定位置，后者便于覆盖运动范围，按场景选用。
- **手动对焦**：可结合放大和峰值辅助，但峰值提示不等于一定精确合焦。
- **连拍**：同时检查自动对焦、自动曝光、RAW位深、缓存和写卡限制，不只看最高张数。
- **机身／镜头防抖**：主要减轻相机晃动，不能阻止人物、宠物等主体运动。
- **电子快门**：部分设备可能出现滚动快门变形、灯光条纹或闪光限制；全局快门等实现需单独核对。

### 照片格式与后期

| 格式 | 特点 | 处理要点 |
| :--- | :--- | :--- |
| JPEG | 相机已完成较多图像处理，分享方便 | 注意白平衡、风格和曝光，反复有损保存会降低质量 |
| HEIF等 | 可提供不同压缩或色彩能力，依具体实现 | 检查手机、电脑、软件及平台兼容性 |
| RAW | 保留较多原始采样数据与元信息，便于调整 | 文件较大，需要兼容软件，不能保证救回所有曝光或对焦错误 |
| RAW＋JPEG | 同时保留处理空间与快速预览文件 | 占用和写入量增加，整理时避免漏备份 |

后期可按“筛片 → 镜头校正 → 曝光与白平衡 → 局部调整 → 输出”处理。先保留原文件，再根据用途导出尺寸和格式，避免覆盖唯一原片。

### 视频参数

| 参数 | 影响与检查点 |
| :--- | :--- |
| 分辨率 | 决定输出采样规模；同为4K也有不同读取、裁切和处理方式 |
| 帧率 | 影响运动表现与慢放空间，需配合后期时间线 |
| 快门 | 影响每帧运动模糊；约为帧率倒数一半的曝光时间是常见起点，不是必须规则 |
| 位深 | 影响可表示的色阶，例如10-bit与8-bit；仍受编码、曝光和后期影响 |
| 色度采样 | 4:2:0、4:2:2等描述色彩采样方式，不等同于分辨率或位深 |
| 码率与编码 | 影响体积、记录质量和剪辑负担，同码率跨编码不能简单比较 |
| Log | 为后期处理保留特定影调分配，通常需要正确曝光及色彩转换 |
| HDR | 涉及记录、监看、剪辑与播放链路，不只是画面更鲜艳 |
| 防抖与裁切 | 关注实际视角、画面边缘变化及走动时的稳定效果 |
| 散热与时长 | 目标模式下测试连续录制、供电和环境限制 |
| 音频 | 检查麦克风、接口、监听、底噪及风噪控制 |

- 照片像素高，不代表视频一定清晰、低噪或没有裁切。
- Log不是自动提升画质的开关；不做相应后期时，常规影调可能更适合直接交付。
- 高帧率拍摄慢放常需要更充足的光线；拍摄帧率与回放帧率应提前规划。
- 录制前用目标电脑导入一段实际素材，检查解码、剪辑、色彩与存储流程。

来源：[Sony：视频录制基本设置](https://www.sony.com/zh-cn/electronics/support/articles/00268257)。

### 存储卡与配件

#### 存储卡

- 先看机身要求的卡类型、容量、速度等级及支持模式，SD与CFexpress不能仅凭外形相近互换。
- CFexpress Type A与Type B不是同一种尺寸与接口规格；双卡槽也可能有不同能力。
- 标注的最高读取速度不等于持续写入速度，视频更要核对机身要求的速度等级。
- V30、V60、V90对应规定条件下最低持续写入速度30、60、90MB/s；是否支持某个录制模式仍看相机要求。
- 码率通常写作Mb/s，卡速常写作MB/s，换算时除以8；例如200Mb/s约为25MB/s，但选卡还需余量及官方兼容要求。
- 卡槽和读卡器也会限制速度，不能只购买更高标称卡速就期待所有环节变快。
- 备份并核验后再在相机内格式化，不在写入中断电或拔卡；双卡备份不能替代拍摄后的独立备份。

来源：[SD协会：速度等级](https://www.sdcard.org/developers/sd-standard-overview/speed-class/)、[富士：相机存储卡使用指南](https://www.fujifilm.com.cn/cn/zh-hans/consumer/digitalcameras/consumer/support/digitalcameras/service/SD)。

#### 其他配件

| 配件 | 先核对 |
| :--- | :--- |
| 备用电池与充电器 | 型号、认证、接口及供电要求 |
| 肩带／腕带 | 固定方式、连接件状态和佩戴舒适度 |
| 三脚架与云台 | 实际稳定性、快装兼容、总重量和使用场景 |
| 闪光灯 | 卡口触点协议、TTL／高速同步、触发系统与光线控制 |
| 持续灯 | 亮度、色彩、散热、供电及调光频闪表现 |
| ND滤镜 | 在明亮环境控制曝光，核对口径、偏色与暗角 |
| CPL偏振镜 | 控制部分反光，效果依角度，且会损失部分光量 |
| 麦克风 | 接口、供电、收音方向和监听方式 |
| 相机包与防雨罩 | 装入实际镜头组合，兼顾取放、背负和天气 |

遮光罩可帮助减少部分杂光并提供一定物理遮挡；保护镜并非必装，使用时注意质量、反光与清洁。

### 按题材选购

| 题材 | 优先考虑 | 常见取舍 |
| :--- | :--- | :--- |
| 旅行与随身记录 | 全套重量、焦段、续航、操作和分享 | 少量镜头与覆盖范围之间的平衡 |
| 人像 | 焦段、对焦、光圈、肤色与补光 | 镜头工作距离、景深和体积 |
| 儿童与宠物 | 对焦追踪、快门、启动响应 | 光线不足时的运动清晰度 |
| 风景与建筑 | 镜头、动态范围、支撑和携带 | 边缘画质、滤镜及长曝光流程 |
| 鸟类与运动 | 长焦、持续对焦、连拍、缓存 | 整套重量、成本和取景难度 |
| 小物与微距 | 放大倍率、工作距离、补光 | 景深很浅，可能需要支撑或堆栈 |
| 视频与日常记录 | 对焦、防抖、收音、翻转屏、散热 | 裁切、后期负担和附件体积 |

预算按“机身＋镜头＋卡与电池＋必要配件＋存储与后期”计算。没有明确需求时，先试用或租用接近目标的组合，确认愿意携带和整理素材，再增加投入。

### 新机与二手检查

- 核对机身、镜头准确型号、销售地区、购买凭证、保修及配件清单。
- 检查屏幕、取景器、按键、卡槽、接口、电池仓、卡口和外观状态。
- 测试自动及手动对焦、光圈、变焦、防抖、连拍、视频和目标外接设备。
- 拍不同光圈和亮度的样张，检查明显异常；区分灰尘、热像素和正常拍摄噪点，必要时请维修人员判断。
- 镜头检查霉斑、雾化、明显划伤、异常松动和对焦变焦故障，少量内部灰尘不能直接等同于报废。
- 二手机器的快门次数只是参考，不能反映全部视频使用、电子快门、进液、跌落和维修经历。
- 双卡、视频等功能按自己的目标模式实测，不只完成一张照片就结束验机。
- 明确退换条件和售后责任，避免仅依据序列号或“低快门”判断来源与状态。

### 使用与维护

详细步骤见：[数码产品保养](保养.md)。

- 换镜头时减少暴露时间，避开风沙，避免直接触碰传感器或快门结构。
- 镜头先去除浮尘，再按官方要求清洁；传感器清洁不熟悉时交给正规服务人员。
- 从寒冷环境进入温暖潮湿处时，注意温差凝露，按说明书要求逐步适应环境。
- 收纳前保持干燥，按设备要求使用防潮设施，不把长期放在密闭潮湿相机包中当作保护。
- 拍摄后及时导出并检查，重要素材至少有独立副本；确认备份后再清空卡。
- 避免让强烈激光或不适当的强光直射成像系统，遵守具体设备说明。

来源：[Sony：如何存放相机与镜头](https://www.sony.com/zh-cn/electronics/support/articles/00160168?showHeaderFooter=false)、[尼康：相机保养说明](https://onlinemanual.nikonimglib.com/zr/zh-cn/15-06.html)。

### 常见问题排查

| 问题 | 优先排查 |
| :--- | :--- |
| 照片整体模糊 | 快门过慢、手抖、主体运动、对焦错误或镜片污渍 |
| 只有主体局部清楚 | 景深、对焦位置、主体姿态与拍摄距离 |
| 暗光噪点多 | 实际光量、曝光、ISO、后期提亮及输出尺寸 |
| 电子快门拍灯光有条纹 | 光源频闪、读出方式及快门设置，尝试机身支持的防频闪设置或其他快门模式 |
| 视频画面歪斜 | 滚动快门、快速运动或摇摄，调整拍法并核对目标模式 |
| 录制突然停止 | 卡速、温度、供电、容量或模式时长限制 |
| RAW在电脑上颜色不同 | 软件默认处理、相机风格、色彩管理和显示链路 |
| 存储卡读写异常 | 停止继续写入，保留原卡，先判断是否需要数据恢复，不立即格式化 |

### 入门练习顺序

1. 熟悉持机、对焦点选择、回放放大和曝光检查。
2. 固定拍摄对象，每次只改变光圈、快门或ISO中的一项，观察结果。
3. 练习判断主体是否运动，再选择能满足清晰度要求的快门。
4. 改变拍摄位置和取景，观察透视、背景及画面层次。
5. 拍后筛选少量照片，记录成功或失败的具体原因。
6. 熟悉基础操作后，再学习闪光、长曝光、Log或其他专项技术。
