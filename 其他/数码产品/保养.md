## 台式机

### 1. 日常使用

-   **开关机**：每天使用结束后可以正常关机，也可以根据需要使用睡眠模式。无需为了保护硬件而强制每天关机。
-   **连续运行**：台式机可以长时间连续运行，前提是散热、电源和运行环境正常。没有必须定期关机的硬件要求。
-   **放置位置**：放在平稳、坚固、通风的位置，不要堵住机箱进风口和出风口。
-   **散热环境**：避免阳光直射、暖气附近、高湿度或积灰严重的环境。机箱四周应留出必要的通风空间。
-   **高负载使用**：游戏、视频渲染或编译程序时，关注异常高温、频繁降频、风扇噪声和意外关机。
-   **移动设备**：机械硬盘正在运行时，避免移动或撞击机箱。
-   **电源使用**：使用质量可靠的电源、插座和电源线。经常停电的环境可考虑 UPS。
-   **外接设备**：拔出移动硬盘或 U 盘前，先确保写入完成并安全弹出。

### 2. 硬件保养

| 部件       | 保养方法                     | 检查频率      |
| ---------- | ---------------------------- | ------------- |
| 机箱       | 清除表面灰尘，保持通风       | 每月          |
| 防尘网     | 根据积灰程度清洗，晾干后装回 | 1～3 个月检查 |
| 散热风扇   | 检查积灰、异响和转动状态     | 3～6 个月     |
| CPU 散热器 | 清除灰尘，检查散热性能       | 6～12 个月    |
| GPU        | 检查温度、风扇和积灰情况     | 3～6 个月     |
| 显示器     | 使用柔软无绒布清洁屏幕       | 按需          |
| 电源与线缆 | 检查松动、破损、异常发热     | 3～6 个月     |
| HDD / SSD  | 检查健康状态和备份情况       | 1～3 个月     |

**清灰注意事项：**

1.  完全关机，关闭电源并拔掉电源线。
2.  使用合适的电子设备清洁工具，避免产生静电。
3.  使用罐装压缩空气时，按产品说明操作，避免液态喷剂进入设备；不要让风扇被气流吹得高速旋转。
4.  不要用普通吸尘器直接接触主板和电子元件。
5.  不要拆开电脑电源内部进行清洁。
6.  散热正常时，无须定期拆卸 CPU 或 GPU 散热器、更换硅脂。

### 3. 系统与数据维护

-   **系统更新**：在受支持的操作系统上及时安装安全更新。
-   **驱动更新**：优先使用系统更新、硬件厂商官网或官方管理工具。不必追求每一个新驱动版本。
-   **BIOS / UEFI**：存在安全修复、兼容性问题或必要功能更新时再升级，更新过程中不能断电。
-   **SSD**：保持合理的可用空间，启用系统正常的 TRIM 机制；不要手动进行不必要的传统碎片整理。
-   **HDD**：关注 SMART 健康信息、异常声音和坏扇区，发现问题及时备份。
-   **软件管理**：卸载不使用的软件，减少不必要的开机启动项。
-   **备份数据**：重要文件至少保留一份独立备份，关键资料采用 3-2-1 备份策略。

>   Windows 10 已于 2025 年 10 月 14 日结束常规支持。仍在使用的设备应确认是否具备有效的扩展安全更新支持，或升级到受支持的操作系统。

### 4. 长时间不使用

| 闲置时间   | 推荐处理方式                                   |
| ---------- | ---------------------------------------------- |
| 1～7 天    | 正常关机即可；环境安全时无需特殊保养           |
| 1～4 周    | 关机、断开外部电源，做好防尘                   |
| 1～3 个月  | 清洁机箱、备份数据、断电，存放在干燥通风环境   |
| 3～12 个月 | 除上述操作外，定期检查潮湿、腐蚀和鼠虫侵入情况 |
| 超过 1 年  | 重点检查存储数据的可读性、电源与主板电池状态   |

**长期闲置注意事项：**

-   无需为了“激活硬件”而每周或每月强制开机。
-   完全关机后，长期闲置可拔掉主机和显示器的外部电源。
-   可以使用防尘罩，但应保证设备完全冷却和干燥后再覆盖。
-   不要使用普通塑料袋在潮湿环境中直接密封设备。
-   机械硬盘和固态硬盘都不适合作为重要数据的唯一长期存储介质。
-   主板 CMOS / RTC 电池可能随着时间耗尽，导致时间或部分固件设置丢失；出现症状时再检查和更换。

### 5. 重新启用

1.  检查机箱、接口、电源线、风扇和防尘网。
2.  如果设备从寒冷环境移入温暖环境，等待温度平衡，确认没有凝露。
3.  接通电源，正常启动。
4.  检查风扇、温度、硬盘健康状态及系统时间。
5.  安装必要安全更新，运行安全检查。
6.  检查备份文件是否能够正常读取。

### 6. 常见误区

-   **误区 1：电脑每天必须关机。** 错误。根据实际使用需求选择关机、睡眠即可。
-   **误区 2：电脑连续运行一定会损坏硬件。** 错误。正常散热和稳定供电更重要。
-   **误区 3：CPU 必须每年更换硅脂。** 错误。应依据散热性能和硅脂实际状态决定。
-   **误区 4：SSD 必须定期进行传统磁盘碎片整理。** 错误。正常使用系统自带的存储优化即可。

## Windows 笔记本

### 1. 日常使用

-   **使用环境**：放在平整、坚硬、通风的桌面，避免放在床、枕头或柔软织物上堵塞散热口。
-   **长时间插电**：可以连接适配器持续使用，优先启用厂商提供的电池保护或智能充电功能。
-   **高负载运行**：游戏、编译、渲染时可连接合适功率的原装或兼容适配器。
-   **睡眠与休眠**：短时间离开使用睡眠；长时间不用或携带运输时，优先选择休眠或完全关机。
-   **携带运输**：放入背包前确认设备已真正进入休眠或关机，避免意外唤醒导致包内过热。
-   **屏幕转轴**：从屏幕中间附近平稳开合，不要用力扭转屏幕。
-   **设备表面**：不要在合盖的电脑上放置重物。

### 2. 电池与充电

| 使用场景     | 推荐做法                                   |
| ------------ | ------------------------------------------ |
| 日常使用     | 有条件时保持约 20%～80% 电量               |
| 长期插电办公 | 启用电池保护模式，按机型设置合适的充电上限 |
| 经常外出     | 可以充至 100%，优先保证正常续航            |
| 电量低于 20% | 方便时补电，避免经常完全耗尽               |
| 高温使用     | 降低负载并改善散热，避免高温下持续充电     |
| 长期闲置     | 电量约 40%～60%，关机保存                  |

**电池保护功能：**

不同品牌可能通过 Lenovo Vantage、MyASUS、Dell Optimizer、HP 官方工具或设备 BIOS 提供电池充电限制功能。

-   长期插电使用时，可以优先采用厂商推荐的保护模式。
-   充电上限通常设置在 60%～80% 左右，但具体范围取决于厂商。
-   不必为了保持指定电量而反复手动拔插充电器。
-   电池偶尔充到 100% 并不会直接造成损坏，重点是减少长期满电与高温叠加。

**检查电池健康：**

打开 Windows 终端或命令提示符：

```
powercfg /batteryreport
```

在生成的报告中关注：

-   `DESIGN CAPACITY`：设计容量。
-   `FULL CHARGE CAPACITY`：当前可充满容量。
-   `CYCLE COUNT`：循环次数（不一定所有设备都提供）。

可用以下公式粗略估算相对容量：

```
当前容量 / 设计容量 × 100%
```

该值仅作为参考，不等于精确的电池健康诊断。

### 3. 清洁与硬件保养

-   定期清除机身、屏幕、键盘和散热孔的灰尘。
-   清洁前关机并拔掉适配器。
-   使用微湿的无绒布擦拭外壳和屏幕，避免液体进入接口。
-   不要自行往键盘、风扇或接口内喷洒酒精、清洁剂。
-   风扇噪声异常、设备降频或温度异常时检查散热系统。
-   如果没有拆机经验，不建议自行拆卸散热模组或内置电池。
-   保持散热口畅通，合理使用笔记本支架。

### 4. 软件与数据维护

-   使用 Windows Update 安装必要安全更新。
-   通过笔记本厂商的官方工具获取驱动和固件更新。
-   使用 Windows 安全中心检查设备安全状况。
-   使用“任务管理器”检查异常占用资源的程序。
-   清理不必要的软件及启动项，不依赖第三方所谓一键优化工具。
-   使用文件历史记录、外接硬盘或可信云服务备份重要文件。
-   更新 BIOS 时，确保有稳定供电并遵循厂商说明。

### 5. 长时间不使用

| 闲置时间    | 推荐做法                              |
| ----------- | ------------------------------------- |
| 1～7 天     | 可以正常关机；无需专门调整电池        |
| 1～4 周     | 充至约 40%～60%，完全关机并拔掉适配器 |
| 1～3 个月   | 保持中等电量，做好清洁和防潮          |
| 3～6 个月   | 定期检查剩余电量，避免过度放电        |
| 超过 6 个月 | 继续定期检查，必要时补电至约 40%～60% |

**注意：**

-   长期闲置不能仅合盖进入睡眠，应完全关机。
-   关闭后部分设备仍可能存在少量电池消耗。
-   内置电池不需要为了存放而自行拆除。
-   如果厂商对长期存放、运输模式或可拆卸电池有特别说明，优先执行官方要求。
-   长期存放电量不宜为 0% 或 100%。

### 6. 重新启用

1.  检查电池是否鼓包、外壳是否变形。
2.  连接适配器，必要时先充电一段时间。
3.  正常开机，检查电池是否能正常充放电。
4.  安装安全更新，检查系统和硬盘。
5.  观察温度、风扇和性能是否正常。

### 7. 常见误区

-   **误区 5：笔记本长期插电一定损坏电池。** 不准确。长期满电和高温会加速老化，智能充电与良好散热能减轻影响。
-   **误区 6：必须把电池用到 0% 才能充电。** 错误。现代锂电池不需要这样做。
-   **误区 7：电池只有定期完整充放电才能保持健康。** 错误。完整充放电并非必要保养方式，某些厂商要求的电量校准属于特定情况。

## MacBook

### 1. 日常使用

-   **正常使用**：短时间离开可合盖睡眠；长期不使用时选择关机。
-   **长期插电**：可以持续连接电源，建议开启 macOS 自带的电池优化功能。
-   **散热**：在坚硬、平整、通风的表面使用，不要遮挡通风位置。
-   **高负载任务**：视频剪辑、编译和渲染期间，允许设备正常散热。
-   **屏幕保护**：不要在键盘和屏幕之间放置厚键盘膜、摄像头盖或其他物品后合盖。
-   **外部设备**：连接扩展坞和外接显示器时，使用合规且供电能力适当的配件。
-   **外出携带**：确保设备已进入合适的低功耗状态，避免背包内意外运行。

### 2. 电池与充电

**推荐策略：**

-   开启“优化电池充电”，减少电池长时间处于满电状态。
-   长期插电使用时，优先使用系统提供的电池管理功能。
-   短期外出可以充满电，不必刻意限制续航。
-   日常尽量避免长时间处于高温、满电状态。
-   不需要定期将电池耗尽进行所谓激活。

**设置路径：**

```
系统设置 → 电池 → 电池健康 / 充电
```

具体名称随 macOS 版本而变化。

部分配备 Apple 芯片、运行 macOS Tahoe 26.4 或更新版本的 MacBook，还支持设置 80%～100% 的充电上限。

**检查电池：**

```
系统设置 → 电池 → 电池健康
```

还可以通过：

```
系统信息 → 硬件 → 电源
```

查看循环次数及相关电池数据。

**判断是否需要更换：**

-   续航明显缩短。
-   系统显示建议维修。
-   电池发生异常发热、鼓包或其他物理损坏。
-   设备频繁发生无法解释的电池供电关机。

不要仅根据某个固定循环次数判断电池必须更换。

### 3. 清洁与系统保养

-   关闭 MacBook 并断开电源，再进行清洁。
-   使用柔软、微湿的无绒布清洁屏幕和机身。
-   不要直接向屏幕喷洒清洁液。
-   避免使用含氨玻璃清洁剂、研磨剂或未经允许的溶剂。
-   配备纳米纹理显示屏的型号应遵循专用清洁说明。
-   定期检查 USB-C、MagSafe 接口是否有异物。
-   保持 macOS 和常用软件的安全更新。
-   避免安装来源不明的系统优化工具。

**数据备份：**

使用 `系统设置 → 通用 → 时间机器（Time Machine）` 配置外部备份磁盘。

重要文件建议同时保留独立的离线或异地备份。

### 4. 长时间不使用

| 闲置时间    | 推荐做法                                 |
| ----------- | ---------------------------------------- |
| 1～7 天     | 正常关机或根据实际需要使用睡眠           |
| 1～4 周     | 电量约 50%，关机并断开适配器             |
| 1～3 个月   | 保持约 50% 电量，存放于阴凉干燥处        |
| 3～6 个月   | 定期检查设备及电量状况                   |
| 超过 6 个月 | 按 Apple 官方建议，每 6 个月补电至约 50% |

**长期存放条件：**

-   保持环境凉爽、干燥，避免阳光直射。
-   Apple 建议长期保存时的温度低于 32℃。
-   不要在 0% 电量或长时间满电状态下存放。
-   完全关机后拔掉电源及外接设备。
-   清洁干燥后放入合适的防尘保护套。
-   避免重物压迫屏幕和外壳。

### 5. 重新启用

1.  检查机身、电池、接口和屏幕。
2.  如电量较低，先连接适配器。
3.  等待设备正常启动，不要连续强制开关机。
4.  检查电池健康状态及系统时间。
5.  更新 macOS 和重要软件。
6.  检查 Time Machine 备份状态。

### 6. 常见误区

-   **误区 8：MacBook 必须经常把电量用尽。** 错误。锂电池不需要定期深度放电。
-   **误区 9：MacBook 插电时必须每隔几小时拔一次电源。** 错误。优先使用系统电池优化功能。
-   **误区 10：MacBook 永远不需要清理散热系统。** 错误。应根据积灰、噪声和实际散热表现判断。

## iPhone

### 1. 日常使用

-   **开关机**：日常无需每天关机，也不需要强制定期重启。
-   **使用环境**：避免阳光直射、高温车内和高湿度环境。
-   **高负载使用**：游戏、视频录制、导航时注意设备温度。
-   **充电使用**：可以边充电边使用，但高负载叠加充电产生的热量可能加速电池老化。
-   **防水能力**：防水性能并非永久不变，不能将防水等级视为绝对安全保证。
-   **接口保护**：避免充电接口进入水分、灰尘及金属异物。
-   **手机保护**：使用合适的保护壳，避免长时间挤压和跌落。

### 2. 电池与充电

| 使用情况   | 推荐做法                               |
| ---------- | -------------------------------------- |
| 日常充电   | 根据使用习惯选择充电范围，不必刻意用尽 |
| 经常插电   | 开启充电优化或设置适合的充电上限       |
| 需要长续航 | 可以正常充至 100%                      |
| 高温环境   | 避免持续快速充电和高负载运行           |
| 无线充电   | 可以使用，关注设备是否明显发热         |
| 长期闲置   | 电量约 50%，关机保存                   |

**充电上限：**

iPhone 15 及更新机型支持设置充电上限。

设置位置：

```
设置 → 电池 → 充电
```

可根据需要选择合适的限制电量。

iPhone 14 及更早机型主要通过“优化电池充电”减少长时间保持满电的情况。

**电池健康检查：**

```
设置 → 电池 → 电池健康
```

不同机型、系统版本的具体页面可能有所区别。

重点关注：

-   最大容量。
-   峰值性能或维修提示。
-   续航变化。
-   异常发热与意外关机。

**充电建议：**

-   使用符合安全标准、兼容设备的充电器和线缆。
-   不必等到电量低于 20% 才开始充电。
-   充电一整夜不意味着必然损坏电池。
-   尽量减少高温环境下持续充电。
-   电池出现异常鼓包、异味或过热时，应停止使用和充电。

### 3. 清洁与系统维护

-   使用柔软无绒布擦拭屏幕和外壳。
-   必要时可按照 Apple 指南使用适当的消毒湿巾清洁外表面。
-   不要把清洁剂直接喷入充电口、扬声器或其他开孔。
-   不要使用金属针具清理充电接口。
-   不要使用高压气流清洁手机内部。
-   及时安装 iOS 安全更新。
-   检查应用权限，删除不再使用的软件。
-   开启“查找”和合适的账号保护措施。

**数据备份：**

使用：

```
设置 → Apple 账户 → iCloud → iCloud 云备份
```

也可使用 Mac 或 Windows 电脑进行本地备份。

重要数据不能仅依赖单一设备。尤其要确认照片、聊天记录及身份验证数据已妥善保存。

### 4. 长时间不使用

| 闲置时间    | 推荐做法                                 |
| ----------- | ---------------------------------------- |
| 1～7 天     | 正常放置即可；如确定不用，可以关机       |
| 1～4 周     | 电量约 50%，关机保存                     |
| 1～3 个月   | 关机、防潮、防高温，检查电量是否异常下降 |
| 3～6 个月   | 根据电量变化检查是否需要补电             |
| 超过 6 个月 | Apple 建议每 6 个月补电至约 50%          |

**存放前操作：**

1.  备份照片、文件及重要应用数据。
2.  将电池电量调整至约 50%。
3.  完全关闭手机。
4.  断开充电线和外接配件。
5.  擦拭手机并保持机身干燥。
6.  放在阴凉、干燥、避免阳光直射的位置。

**注意：**

-   不要以 0% 电量长期存放。
-   不建议以 100% 电量在高温环境中长期保存。
-   不必为了“激活电池”而频繁开机。
-   备用手机若仍承担接收短信、双重验证等任务，则应正常维护而非完全关机存放。

### 5. 重新启用

-   检查是否有外壳变形、电池鼓包或异常发热。
-   必要时先连接充电器一段时间。
-   正常开机后检查充电功能。
-   更新 iOS 和重要应用。
-   检查 Apple 账户、蜂窝网络和数据备份。

### 6. 常见误区

-   **误区 11：新 iPhone 第一次充电必须充满 12 小时。** 错误。现代锂电池无需这种操作。
-   **误区 12：每次充电达到 100% 都会明显损坏电池。** 错误。需要关注长期满电、高温和整体使用条件。
-   **误区 13：iPhone 有防水等级就可以放心长期泡水。** 错误。防水性能存在条件限制，并可能随老化和损伤下降。

## Android

### 1. 日常使用

-   不需要每天关机，出现系统异常时再根据需要重启。
-   避免高温、阳光直射、潮湿和严重积灰环境。
-   长时间玩游戏、导航或录制视频时注意散热。
-   不要在明显过热状态下继续高负载运行和充电。
-   避免使用劣质充电器、不合规电池和损坏的线缆。
-   避免安装不可信来源的 APK。
-   及时检查应用权限和后台耗电。
-   具有防水等级的设备仍应避免不必要的液体接触。

### 2. 电池与充电

**通用建议：**

-   日常可参考约 20%～80% 的电量范围，但不必严格遵守。
-   长期接通充电器时，优先开启系统电池保护功能。
-   高温对电池寿命的影响通常比偶尔充满电更值得关注。
-   快充本身不是必须避免的功能，应优先使用合规充电器并控制温度。
-   不需要定期深度放电来维护锂电池。

**不同品牌设置：**

| 品牌           | 电池保护功能                           |
| -------------- | -------------------------------------- |
| Samsung        | 部分 Galaxy 机型支持电池保护和充电限制 |
| Google Pixel   | 部分机型支持自适应充电、80% 充电上限   |
| Xiaomi / Redmi | 部分机型提供智能充电保护或相关设置     |
| OPPO / OnePlus | 部分机型提供智能充电、夜间充电优化     |
| vivo           | 部分机型提供充电优化或电池健康管理     |

具体功能名称和支持程度以设备型号及系统版本为准。

**检查电池状态：**

-   优先使用系统自带的电池健康页面。
-   无法查看最大容量时，可以参考实际续航和官方诊断结果。
-   第三方应用估算出的电池容量未必准确。
-   出现鼓包、异常过热或频繁意外关机时应检查电池。

### 3. 清洁与系统维护

-   使用柔软无绒布清洁屏幕、机身和摄像头保护玻璃。
-   避免液体进入充电口和扬声器。
-   不要使用金属工具深入清理接口。
-   安装系统安全更新和应用更新。
-   使用 Google Play 或设备厂商提供的可信应用商店。
-   定期检查应用权限、后台耗电与存储空间。
-   对不再使用的软件进行卸载。
-   不依赖所谓的内存加速、强制清理后台等优化软件。

**数据备份：**

可根据设备使用 Google 账号备份：

```
设置 → Google → 备份
```

部分品牌还提供自己的云备份或电脑本地备份工具。

需要分别检查照片、通讯录、聊天记录、应用数据与双重验证工具是否完成备份。

### 4. 长时间不使用

| 闲置时间    | 推荐做法                           |
| ----------- | ---------------------------------- |
| 1～7 天     | 正常关机即可                       |
| 1～4 周     | 电量约 40%～60%，完全关机          |
| 1～3 个月   | 防潮、防高温，避免电池过度放电     |
| 3～6 个月   | 检查剩余电量，必要时补电           |
| 超过 6 个月 | 持续定期检查，具体频率遵循厂商说明 |

**存放要求：**

-   优先选择温度稳定、干燥的室内环境。
-   不要满电或完全没电长期保存。
-   关闭设备，而不只是开启飞行模式。
-   不需要定期将电池耗尽。
-   可拆卸电池机型按官方说明处理。
-   若长期不使用手机号，提前处理 SIM 卡、eSIM 和账号验证问题。

### 5. 重新启用

1.  检查电池、屏幕、充电口及外壳。
2.  必要时先充电，再正常开机。
3.  检查电池续航及异常发热情况。
4.  更新 Android 系统和应用。
5.  检查账号登录、备份、网络和应用兼容性。
6.  如果设备已经停止获得安全更新，避免继续承担敏感业务。

### 6. 常见误区

-   **误区 14：必须每周进行一次完整充放电。** 错误。没有适用于所有 Android 手机的这种要求。
-   **误区 15：定期清理运行内存一定能提升速度。** 错误。Android 自身具有内存管理机制，频繁强制清理可能增加重新启动应用的负担。
-   **误区 16：快充一定比普通充电更伤电池。** 不准确。实际影响与温度、电池设计、充电管理和充电器兼容性有关。

## 相机

*主要适用于数码单反、无反相机及可更换镜头的数码相机；采用内置电池、特殊电池或防水结构的型号，应优先参考对应说明书。*

### 1. 日常使用

-   **开关机**：更换电池或存储卡前，先按照说明书关闭相机。
-   **镜头保护**：不拍摄时使用镜头盖，避免镜片划伤和直接接触。
-   **更换镜头**：选择干净、少尘的环境，缩短机身卡口暴露时间。
-   **传感器保护**：避免用手、纸巾或普通清洁工具直接触碰传感器。
-   **防潮防霉**：避免相机长期处于潮湿、不通风的环境。
-   **防高温**：不要将相机长时间放在暴晒的汽车内部。
-   **防震防摔**：携带相机时使用合适的肩带、收纳包或保护箱。
-   **防水限制**：防尘防滴溅结构并不代表相机可以浸水。

**拍摄完成后：**

1.  关闭相机。
2.  根据环境清除机身和镜头表面的灰尘。
3.  必要时盖上镜头前盖和后盖。
4.  将照片导入电脑或其他存储设备。
5.  检查电池剩余电量。
6.  潮湿环境使用后，确保设备表面干燥再存放。

### 2. 电池保养与充电

相机使用的电池类型和厂商存放要求可能不同，不能将手机的电池规则直接套用到所有相机。

**日常建议：**

-   使用厂商认可的电池和充电器。
-   避免高温下长时间充电。
-   电池使用后发热明显时，先等待其降至适合充电的温度。
-   长期不使用时，通常应将可拆卸电池从相机中取出。
-   拆出的电池应做好触点保护，避免与金属物品接触。
-   不要长期把备用电池放在高温汽车内。

**长期存放电量：**

-   现代锂离子电池通常适合中等电量存放，约 40%～60% 可作为一般参考。
-   但部分相机厂商或特定型号的说明书存在不同的电池存储要求。
-   **必须优先遵守电池及相机型号的官方说明，不要强行执行统一的充放电周期。**
-   不要把深度过放当作普遍适用的保养方法。

### 3. 镜头与机身清洁

| 部件         | 推荐保养方法                                           |
| ------------ | ------------------------------------------------------ |
| 镜头前后镜片 | 先用摄影气吹去除颗粒，再用合适的镜头布与清洁液按需清洁 |
| 镜头外壳     | 使用柔软干布清洁                                       |
| 镜头卡口     | 保持干燥、清洁，不随意触碰电子触点                     |
| 相机传感器   | 优先使用相机自带清洁功能；必要时交给专业人员           |
| 取景器       | 使用气吹及合适的软布清洁                               |
| 相机屏幕     | 使用柔软无绒布擦拭                                     |
| 电池仓       | 保持干燥，检查触点是否腐蚀                             |
| 存储卡槽     | 避免灰尘、水分与异物进入                               |

**重要注意事项：**

-   不要直接用嘴向镜头或传感器吹气。
-   不要使用普通纸巾摩擦镜头表面。
-   不建议用罐装压缩空气直接吹相机传感器。
-   镜头内部发霉或存在复杂污渍时，应交由专业人员处理。
-   不要随意拆卸镜头内部结构。

### 4. 防潮箱和存储环境

相机与镜头长期存放时，湿度管理尤其重要。

**推荐方式：**

-   使用电子防潮箱存放相机和镜头。
-   可将相对湿度控制在约 40%～50%，这是 Sony 提供的相机及镜头保存建议。
-   使用湿度计检查实际湿度。
-   避免长期处于湿度很高、通风差的环境。
-   避免极端高温、低温及温差剧烈变化。
-   不要单纯追求湿度越低越好。
-   使用普通密封箱和干燥剂时，定期检查干燥剂与湿度。

**存放镜头：**

-   保持镜片和镜头外壳干燥。
-   盖好镜头盖。
-   有机身盖和镜头后盖时，可以分开存放机身和镜头。
-   不要把未经干燥处理的相机长期密封在普通摄影包中。
-   应防止镜头受到长时间挤压或撞击。

### 5. 存储卡与照片管理

-   拍摄完成后及时备份照片与视频。
-   不要把 SD 卡、CFexpress 卡等作为唯一存储位置。
-   至少在两个独立位置保存重要照片。
-   确认备份完成后，再根据实际需要格式化存储卡。
-   格式化前确认所选存储卡和文件内容，避免误删。
-   存储卡应避免高温、潮湿、静电和物理损伤。
-   出现写入错误、文件损坏或明显不稳定时停止依赖该存储卡。

### 6. 长时间不使用

| 闲置时间    | 推荐做法                                             |
| ----------- | ---------------------------------------------------- |
| 1～7 天     | 关机，盖好镜头盖，放在干燥环境                       |
| 1～4 周     | 清洁机身，建议取出可拆卸电池并妥善保存               |
| 1～3 个月   | 使用防潮箱，检查电池状态和环境湿度                   |
| 3～6 个月   | 定期检查电池、机身和镜头是否有受潮、发霉迹象         |
| 超过 6 个月 | 按电池厂商要求检查或维护电量，检查防潮设备及相机状态 |
| 超过 1 年   | 定期检查机身、镜头、电池、存储卡和照片备份           |

**长期闲置前：**

1.  将照片、视频备份至其他设备。
2.  清洁机身、镜头和显示屏。
3.  确认设备完全干燥。
4.  按厂商要求处理并取出可拆卸电池。
5.  安装机身盖和镜头盖。
6.  存放于防潮箱或合适的干燥环境。
7.  记录电池状态和存放日期。

**注意：**

-   长时间闲置不一定需要频繁开机或拍摄。
-   某些厂商说明书建议定期取出相机操作，以防潮湿环境中发生霉变；这种要求应按具体机型执行。
-   不要用频繁开机代替正确的湿度控制。
-   相机长期闲置，通常更需要关注镜头霉变、储存环境和电池状态。

### 7. 重新启用

1.  检查机身是否受潮、发霉、腐蚀或出现异味。
2.  检查镜头是否有明显霉斑、雾状物或异常机械阻力。
3.  检查电池是否鼓包、漏液或损坏。
4.  确认电池安全后按照要求充电。
5.  安装电池和存储卡，启动相机。
6.  测试快门、对焦、显示屏和存储卡写入。
7.  拍摄测试照片，检查成像有无异常。
8.  按需要检查固件版本和日期设置。

### 8. 常见误区

-   **误区 17：相机长期不使用必须每天或每周开机。** 错误。并不存在适用于所有相机的强制开机周期。
-   **误区 18：镜头放在普通摄影包里就一定不会发霉。** 错误。潮湿的包内环境可能增加霉变风险。
-   **误区 19：防潮箱湿度越低越好。** 错误。应使用厂商建议的合适湿度范围。
-   **误区 20：存储卡可以作为照片的唯一长期备份。** 错误。重要照片应保存在多个独立位置。

## 全设备保养速查：20 条核心建议

1.  设备保持良好散热，避免高温。
2.  避免潮湿、凝露与液体进入电子设备。
3.  无需为了保养而强制每天关机。
4.  长期闲置前应根据设备类型完全关机。
5.  锂电池不需要定期放电到 0%。
6.  日常充电不必机械地限制在固定百分比。
7.  长期满电叠加高温会增加电池老化风险。
8.  长期闲置的锂电池通常适合中等电量存放。
9.  电池存放与维护以设备官方说明为准。
10.  设备电池鼓包、异常发热时应停止使用和充电。
11.  清洁设备前应按要求关机并断电。
12.  不要将清洁液直接喷向屏幕和设备开孔。
13.  不要随意拆卸电源、内置电池或相机传感器。
14.  风扇清灰和硅脂更换应依据实际情况。
15.  操作系统和应用应保持必要的安全更新。
16.  驱动与 BIOS / 固件不需要为了追新而盲目升级。
17.  不依赖来历不明的第三方系统优化软件。
18.  重要数据应保留至少一份独立备份。
19.  长期闲置后重新使用，应先检查设备物理状态。
20.  延长设备寿命的核心是：**正确使用、控制温度、避免损伤、保护数据、合理存放。**
