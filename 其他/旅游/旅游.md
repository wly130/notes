## 旅游

### 出行前准备

- [ ] 提前查看目的地天气预报，确定携带衣物类型
- [ ] 确认证件有效期（护照需6个月以上有效期）
- [ ] 购买旅行保险（出境游强烈建议）
- [ ] 告知银行出行计划，避免异地刷卡被冻结
- [ ] 手机开通国际漫游或购买当地电话卡（出境游）
- [ ] 下载离线地图、翻译软件、出行APP
- [ ] 家中断水断电、关好门窗、倒垃圾
- [ ] 宠物/植物托管安排

---

### 证件与财务

- [ ] 身份证（国内游必备）
- [ ] 护照 + 签证（出境游必备，确保护照有效期 > 6个月）
- [ ] 驾驶证（自驾游/租车必备，出境需国际驾照或翻译件）
- [ ] 银行卡（信用卡 + 储蓄卡，建议带2张不同银行的）
- [ ] 现金（国内少量即可；出境提前换好当地货币，备零钱）
- [ ] 证件复印件/电子扫描件（与原件分开存放，以备遗失）
- [ ] 旅行保险单（打印或电子版）
- [ ] 行程单/酒店预订确认单（出境入境时可能需出示）
- [ ] 学生证/军官证/老年证（景区门票优惠）

> **提示**：证件类建议拍照存手机 + 云端备份一份，纸质复印件与原件分开放

---

### 衣物与穿戴

#### 基础衣物（根据天数调整）

- [ ] 内衣裤（按天数 + 1套备用）
- [ ] 袜子（按天数 + 1双备用）
- [ ] 上衣（按天数减半，可混搭）
- [ ] 裤子/裙子（2~3条，耐脏耐穿优先）
- [ ] 睡衣 1套
- [ ] 平底舒适步行鞋 1双（最重要，不要穿新鞋出行）
- [ ] 拖鞋 1双（酒店可能不提供或不好穿）

#### 季节性衣物

| 季节 | 额外携带 |
| ---- | -------- |
| **春季** | 薄外套/风衣、薄针织衫、围巾（早晚温差大） |
| **夏季** | 防晒衣、遮阳帽、太阳镜、凉鞋/沙滩鞋、泳衣 |
| **秋季** | 卫衣/薄毛衣、轻薄羽绒（北方地区） |
| **冬季** | 厚羽绒服、保暖内衣、围巾/手套/帽子、暖宝宝、雪地靴、厚袜子 |

> **打包技巧**：衣物用卷叠法而非折叠，节省空间且不易起皱；重物放箱底，易皱衣物放最上面

### 洗漱与个人护理

- [ ] 牙刷 + 牙膏（酒店提供的不一定好用）
- [ ] 毛巾/速干毛巾（讲究卫生自带，速干巾更便携）
- [ ] 洁面乳
- [ ] 洗发水/沐浴露（旅行装/分装瓶）
- [ ] 护肤品（水乳霜，分装小瓶）
- [ ] 防晒霜（SPF30+日常，SPF50+户外/海边）
- [ ] 剃须刀（男士）
- [ ] 梳子
- [ ] 卫生纸 + 湿巾
- [ ] 口罩（若干）
- [ ] 指甲刀套装
- [ ] 隐形眼镜 + 护理液（如需要）
- [ ] 女性卫生用品
- [ ] 一次性内裤/一次性毛巾（长途旅行方便换洗）

---

### 电子产品

- [ ] 手机 + 充电器/数据线
- [ ] 充电宝（飞机限带 ≤20000mAh，不可托运必须随身）
- [ ] 耳机（降噪耳机长途旅行神器）
- [ ] 笔记本电脑 + 充电器（按需，商务出差必带）
- [ ] 相机 + 存储卡 + 充电器（旅行摄影爱好者）
- [ ] 万能转换插头（出境游必备，各国插头标准不同）
- [ ] 多口USB充电器（一个充电器充多个设备，减少线缆）
- [ ] 自拍杆/三脚架（按需）

> **提示**：充电宝额定能量超过100Wh需航空公司批准，超过160Wh禁止携带

### 药品与健康

#### 常备药品

- [ ] 感冒药（布洛芬/对乙酰氨基酚）
- [ ] 肠胃药（蒙脱石散、黄连素、健胃消食片）
- [ ] 消炎药（阿莫西林，需处方）
- [ ] 创可贴 + 碘伏棉签
- [ ] 晕车/晕船药（茶苯海明）
- [ ] 过敏药（氯雷他定）
- [ ] 润喉片
- [ ] 驱蚊液/止痒膏（夏季/热带地区）
- [ ] 个人特殊用药（如哮喘喷雾、降压药等）

> **提示**：药品保留原包装和说明书，出境游注意目的地国家对药品的入境限制（如含麻黄碱类药物部分国家禁止）

### 不同出行类型的差异建议

#### 国内短途游（1~3天）

- 背包/小型行李箱即可
- 精简衣物，1~2套换洗
- 电子产品从简，手机+充电宝足够
- 洗漱用品可用酒店的

#### 国内长途游（5天以上）

- 20~24寸行李箱
- 衣物按"天数÷2"准备，途中找洗衣店
- 带折叠晾衣绳/折叠衣架
- 常用药品备齐

#### 出境游

- **必须**：护照+签证、万能转换插头、当地货币/信用卡
- **建议**：旅行保险、翻译APP、离线地图、当地电话卡/eSIM
- **注意**：药品入境限制、液体随身行李限100ml/件、充电宝必须随身
- **推荐**：颈枕、眼罩、耳塞（长途飞机三件套）

#### 商务出差

- 正装/商务休闲装
- 笔记本电脑 + 充电器 + 投影仪转接头
- 名片
- 熨斗/挂烫机（酒店可能有）
- 皮鞋 + 鞋擦

### 打包技巧

| 技巧 | 说明 |
| ---- | ---- |
| **卷叠法** | 衣物卷成筒状，比折叠节省约30%空间，且不易起皱 |
| **分类收纳袋** | 用收纳袋按类别分装（衣物袋、洗漱袋、电子袋），找东西方便 |
| **重下轻上** | 行李箱竖放时重物在底部（轮子侧），轻物在上面 |
| **鞋子塞袜** | 鞋内塞入袜子等小件，既省空间又防鞋变形 |
| **液体防漏** | 洗护用品瓶口包一层保鲜膜再盖盖子，防漏液 |
| **怕皱衣物** | 西装/衬衫等放最上面，或用手提袋套着 |
| **常用物品外置** | 充电宝、耳机、证件等放随身小包，不要放行李箱（飞机/火车随时要用） |
